# 商户端开发版基线调整

确认：2026-09-28，以已登录的开发版商户端为已有页面基线，保留统一 Demo 的已确认扩展。只读取页面，不改变线上账号、订单、资金或配置，不复制线上业务数据。

## 实施与边界

1. 将既有商户 HTML 无损解码为可检索源码，构建时内联到原有 `demoFrame`，保持三端单文件、按需挂载契约。
2. 对齐白色侧栏、紫色主色、页签、筛选卡片、统计条、表格分页和首页账户分区。
3. 订单管理：代收、代付、虚拟币充值（主池/自有地址）、虚拟币代付、手动下单；账户记录和预付按代收/代付拆分；新增预付服务费流水、日终双币种、余额下发提现。
4. 对接信息对齐商户信息、安全密钥、API 地址、已开通产品分区，所有值均为虚构示例。
5. 根据同日后续确认，移除“Demo 已确认扩展”整组七个入口及跨页链接，不再展示旧扩展页面；仅独立保留账号权限、通知机器人和消息通知配置。原授权页面 ID 和动作权限继续生效，不增加隐式授权。旧数据初始化依赖仍保留在隐藏容器中，不作为可访问页面。
6. 构建/源码一致性、已确认功能标记、运行时导航、筛选、币种、登录与通知回归；检查单文件和窄屏滚动。独立审查构建与权限边界。

新增列表使用明确标记的固定演示数据，不连接开发版接口。手动下单只演示表单校验，不提供旧申请流程跳转。原数据模型不改，不生成任何真实交易。
