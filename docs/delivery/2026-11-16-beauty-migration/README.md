# 美人桥业务原型迁移

平台租户管理对齐现有开发环境的业务页，增加美人桥授权与独立域名组；租户端迁入订单、商户、钱包、统计四个模块，独立商户端迁入订单、首页钱包和钱包记录。本期不迁移骗子库。

业务源由蓝盛原型迁入本仓库独立维护，构建不读取其他项目。原有业务流程沿用，租户授权、租户上下文、本地存储与域名配置分别隔离，列表、地址展示及网址解析使用当前租户配置。

原型不实现真实登录、DNS、网关、证书、资金或回调服务；后端权限、租户隔离和业务规则验收见[开发任务清单](开发任务清单.md)。

统一评审入口为仓库根index.html或GitHub Pages；不以单个业务源码页作为交付入口。
