# 美人桥原型发布验证

发布范围：平台租户美人桥业务授权和独立域名管理；租户端订单、商户、钱包、统计四模块；美人桥商户端订单、首页钱包、钱包记录三页面；商户概览只读地址及按租户隔离的演示状态。骗子库不在本期范围。

发布副本以最新main为基线，仅整理上述功能，不包含本地未发布的审计页等其他需求。临时评审框、专用脚本和加载引用已移除；统一入口由可编辑源重建。

验证：npm run check 376/376通过；完整npm run smoke通过；git diff --check通过。浏览器覆盖四端切换、授权开停、未授权直接路由、双租户读写隔离、跨端网址解析、域名新增启停解绑、地址同步，以及现有商户、通知、订单流程。

本次只发布原型；真实域名、DNS、网关、证书、账号认证、资金、回调与后端租户隔离仍按开发任务清单实现及验收。
