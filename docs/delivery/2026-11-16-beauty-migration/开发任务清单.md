# 美人桥业务迁移到汇盛

## 开发要做

1. 平台端「租户管理 → 详情 → 业务」增加美人桥业务授权，按租户独立开通、停用并记录审计。新租户默认未开通；未开通或停用时，租户端不显示相关菜单，后台和商户端均不能直接访问业务；重新开通保留该租户历史数据。
2. 租户端迁入订单管理、商户管理、钱包管理、统计报表；统一 Demo 顶部提供独立「美人桥商户端」，迁入订单列表、首页钱包、钱包记录。本期不迁移骗子库，后台和商户端都不提供其菜单、页面及接口入口。
3. 商户、子账户、归属、订单、充值、上分、余额、钱包流水、费率及统计数据按租户独立归属和存储。列表、搜索、详情、操作、批量处理、导入、导出和报表均限定当前租户；商户端再限定当前登录商户及原有账号权限。业务规则沿用蓝盛，不与汇盛法币资金或系统费钱包合并。
4. 登录前由服务端按访问域名解析租户，登录后绑定并校验会话租户，不能信任前端传入的租户号。每次请求复验业务授权、角色和按钮权限，以及商户、订单、钱包等对象的租户归属；订单处理、通知、回调、缓存、异步任务和统计汇总均携带并校验租户范围。跨租户读写直接拒绝，失败不改变原数据、不触发资金或发送动作。
5. 接入现有菜单权限、按钮权限、角色授权和审计。迁移数据保留正确租户归属及原有业务关联，关联不明的数据不得混入任一租户；同名商户、相同外部单号不能造成跨租户串联。

6. 平台「租户管理 → 详情 → 域名管理」在租户开通美人桥后增加独立「美人桥商户端域名」区域。提供系统域名及自定义域名的新增、启用、停用和解绑；自定义域名新增后未启用，系统域名不可解绑。启停与解绑沿用原因、当前操作人2FA、权限、租户范围校验和审计。域名全局唯一，不能绑定给其他租户或其他端别；停用业务保留域名记录，重新开通不自动启用已停用域名。美人桥商户端网址沿用汇盛现有域名绑定、状态准入与租户解析机制。当前租户开通美人桥时，在「商户管理 → 详情 → 概览」的原登录地址下方显示只读「美人桥商户端登录地址」；未开通或停用时不显示。地址读取平台当前租户已启用的美人桥域名，多条可用域名均展示；无可用域名时提示由平台启用。同租户美人桥商户共用这些入口，网址确定租户后再验证该租户的美人桥商户账号。未绑定、不可用或所属租户未开通的地址禁止进入，不回退到默认租户；普通商户和美人桥入口按各自端别识别。

## 测试要验

1. 分别验证两个租户的开通、未开通、停用及重新开通：菜单和直接访问符合授权；租户A授权变化不影响租户B，停用不删除历史数据。
2. 核对后台四个业务页面及商户端三个业务页面和原有交互；两个端均无骗子库入口，旧链接和直接接口不能访问本期未迁移的骗子库。
3. 准备两个租户的同名商户和相同外部单号，逐项验证列表、搜索、详情、修改、批量处理、导入导出和统计只包含本租户；商户端不能访问其他租户或同租户无权商户的数据。
4. 篡改租户号、商户号、订单号、钱包号及批量参数，验证后端拒绝越权请求；拒绝后余额、状态、流水、通知均不变化，审计记录对象和租户正确。
5. 验证回调、后台任务、缓存、消息及报表不会串租户；连续进入不同租户、刷新、异步加载和在途请求期间切换上下文，不显示或保存前一租户数据。

6. 验证平台开通后出现美人桥域名区域，新增默认未启用，启用/停用/解绑影响对应访问地址；系统域名不能解绑，重复域名、无权、越租户、缺原因/验证码、在途撤权均不能保存。验证筛选、审计及多可用域名展示，原有两类域名保持原用途。验证两个租户显示不同的美人桥地址；未开通或停用时地址隐藏，重新开通恢复。验证网址解析正确租户、跨租户账号登录失败，未知/不可用域名及篡改租户参数不能进入默认租户；登录会话与访问域名租户不一致时拒绝访问。
