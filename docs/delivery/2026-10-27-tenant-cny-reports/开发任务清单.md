# 开发任务清单

开发执行按业务拆分为两份清单：

- [代收业务报表开发任务清单](代收业务报表开发任务清单.md)：6页。
- [代付业务报表开发任务清单](代付业务报表开发任务清单.md)：6页。

两份清单重点说明迁移蓝盛现有报表、仅保留CNY及已确认的范围调整。本文件保留跨业务字段对照和共用验收要求。

## 开发要做

### 运营中心菜单

- 运营中心提供“日终”和“账户记录”两个可折叠菜单；日终6页、账户记录6页，顺序见下表。进入页面时展开所属菜单，选中当前页面，路径栏显示完整层级。
- 全部页面只展示CNY；蓝盛人民币RMB字段使用CNY名称，不做汇率换算。移除USDT、TRX页签、筛选候选、专属字段和导出内容。
- 商户服务费流水、USDT代付手续费流水不进入本期菜单。

- 不提供代理代收日终统计、代理代付日终统计、代理流水记录；报表列表、合计、导出均不包含代理费、商户代理费、通道代理费。服务费和利润分别保留。

### 日终页面

- 通道页按通道、统计时间、日期范围查询；商户页按商户、统计时间、日期范围查询；平台页按统计时间、日期范围查询。
- 统计时间提供全部时间、今天、昨天、本周、本月；日期使用UTC+8。开始日期不得晚于结束日期。搜索应用条件并回到首页；重置清空条件并恢复全部CNY记录。
- 每页提供搜索、重置、导出、结果条数和分页；表格顺序如下，不合并名称相似的费用、余额或预付字段。

| 页面 | 展示字段（按顺序） |
| --- | --- |
| 代付通道日终统计 | 序号、日期、商户号、商户名称、通道名称、成交金额、总单量、成交率、服务费、利润、备注 |
| 代收通道日终统计 | 序号、日期、商户号、商户名称、通道名称、成交金额、总单量、成交率、服务费、利润、备注 |
| 商户代收日终统计 | 序号、日期、商户名称、成交金额、总单量、成功数、成交率、商户服务费、通道服务费、初期余额、末期余额、余额明细、初期预付、末期预付、预付明细 |
| 商户代付日终统计 | 序号、日期、商户名称、订单总金额、成交金额、未成交金额、总单量、成功数、未支付、成交率、商户服务费、初期余额、末期余额、余额明细、初期预付、末期预付、预付明细 |
| 平台代收日终统计 | 日期、成交额、总单数、成功数、商户服务费、通道服务费、平台利润、平台服务费、商户总余额、商户总预付、通道总余额、通道总预付、代理总余额 |
| 平台代付日终统计 | 日期、成交额、总单数、成功数、商户服务费、通道服务费、平台利润、平台服务费、商户总余额、商户总预付、通道总余额、代理总余额 |

- 通道日终“备注”提供编辑入口，打开时回填当前行，取消保留原备注，保存成功后同步列表；失败保留原内容。只修改本行备注，不修改统计金额。
- 合计覆盖当前筛选的全部记录，不受分页影响；成交率和金额口径迁移蓝盛代码。余额、预付的期初期末快照不能跨日期累加。Demo样例不能作为生产统计或记账算法。
- 商户代付只保留一组CNY预付字段；移除蓝盛末尾属于USDT区域但同名的重复“预付明细”。
- 平台日终按当前租户内业务汇总，不向租户后台返回其他租户数据。

### 账户记录页面

- 六页均提供平台订单号、商户订单号、流水类型、变更起止时间，以及对应通道／商户筛选。按下表展示字段和可选类型。

| 页面 | 展示字段（按顺序） | 流水类型 |
| --- | --- | --- |
| 通道代收流水记录 | 序号、通道名称、平台订单号、商户订单号、类型、币种、原金额、变动金额、变动后金额、变动时间、备注 | 后台调整、代收、结算、下发、活动赠送、其他 |
| 通道代付流水记录 | 序号、通道名称、通道商名称、平台订单号、商户号、类型、币种、原金额、变动金额、变动后金额、变动时间、备注 | 代付退回、后台调整、代付、结算、订单冲销 |
| 商户代收流水记录 | 序号、商户名称、平台订单号、商户订单号、类型、对方商户、对方账户、币种、原金额、变动金额、变动后金额、变动时间、备注、操作 | 后台调整、代收、结算、活动赠送、其他、订单冲正、下发 |
| 商户代付流水记录 | 序号、商户名称、平台订单号、商户订单号、类型、对方商户、对方账户、币种、原金额、变动金额、变动后金额、变动时间、备注、操作 | 后台调整、代付、结算、订单冲销 |
| 商户代付预付记录 | 序号、商户名称、平台订单号、商户订单号、类型、币种、原金额、变动金额、变动后金额、变动时间、备注 | 后台调整、结算、订单冲销 |
| 商户代收预付记录 | 序号、商户名称、平台订单号、商户订单号、类型、币种、原金额、变动金额、变动后金额、变动时间、备注 | 后台调整、结算 |

- 保留“全部类型”和“全部通道／商户”选项；订单号分别匹配原平台订单号、商户订单号，不使用商户号替代商户订单筛选。
- 起止时间精确到秒并包含边界，日期范围支持清空；反向或无效日期提示后保留上次有效查询结果。
- 搜索后回到首页；重置清空全部筛选。分页提供上一页、下一页、页码、每页10／20／50／100条与跳页；空结果显示“暂无数据”。
- 导出当前筛选的全部记录，沿用页面列序、CNY范围与时间格式，不只导出当前页；无数据不生成空文件。对方商户、对方账户和操作列按蓝盛记录实际内容接入，不新增资金操作。
- 流水使用原金额、带方向的变动金额、变动后金额，不将记录页的查看、查询或导出变为资金调整。记录不可覆盖。

### 权限与数据范围

- 为12个菜单入口分别核对菜单可见权限，并维护“运营中心 → 日终／账户记录 → 页面”的权限层级。
- 为查询、导出和通道日终备注编辑维护对应按钮权限。查询和导出应分别鉴权；备注编辑不可沿用仅查看权限。
- 对应后端查询、导出、备注保存接口必须独立校验操作权限和当前租户／可访问对象范围，不能只隐藏前端菜单或按钮。
- 核对目标及既有运营角色的菜单、查询、导出、备注授权，维护角色配置或迁移脚本。正式权限标识由开发核对现有系统与蓝盛，不使用Demo示意标识代替，不自动向全部角色授权。
- 导出及备注保存再次核对当前登录身份、租户和授权；权限不足或上下文变化时提示并保留原数据。导出只允许返回当前授权范围内的数据。

## 测试要验

1. 菜单包含6个日终、6个账户记录，逐个点击进入对应页面；所属菜单、选中项及路径栏一致。直接进入原日终／通道流水路由仍可使用。
2. 逐页对照上表核对列名、列序、流水类型和筛选项。界面、候选项、数据和CSV全部仅CNY，不出现USDT／TRX或重复的预付字段。
3. 对各实体、订单号、类型、日期做单独和组合筛选，结果同时符合全部已应用条件。日期边界包含起止记录；非法或反向日期不替换上次有效结果。
4. 搜索、重置、分页条数、跨页、末页、空态和越界跳页可操作；查询后回到首页，页码与结果条数一致。
5. 导出列序、内容、金额精度、类型和日期与当前全部筛选记录一致；跨页数据完整、无数据不生成文件，备注等文本不得导致CSV公式执行。
6. 日终合计与当前全部筛选记录一致；零单成交率显示合理空值，不发生除零；余额和预付快照不跨日期相加，不能用Demo样例推导生产公式。
7. 通道备注编辑回填正确，保存成功后只更新本行；取消、保存失败、权限不足或租户切换时保留原备注和全部金额。
8. 当前租户无法查询或导出其他租户、其他页面方向、其他币种的数据；平台页同样遵守当前租户范围。查询、分页、导出不改变订单、钱包或预付数据。
9. 分别以有权限和无权限的账号验证菜单可见、按钮可操作及接口访问；目标与既有运营角色授权完整，不出现“能看菜单却无查询权限”或“可查询却可越权导出／编辑”的情况。
