# 开发任务清单摘要

适用范围：租户端 → 系统管理 → 登录安全，包括白名单、手动黑名单、自动临时黑名单配置与恢复。

## 开发要做

1. **页面与查询。**提供白名单、黑名单两个页签，各自只显示对应新增入口；自动拉黑设置仅在黑名单页。支持IP、启用状态、备注和创建时间筛选、搜索、重置、分页及导出；重置回到第一页，切换名单清空勾选，导出已执行搜索范围。
2. **后台仅白名单准入。**新登录必须精确命中当前租户已启用白名单；未知IP、仅命中停用条目、空名单或全部停用均拒绝。有效手动／临时黑名单优先拦截，通过IP准入后仍须通过账号、密码和Google验证码验证。API和已有会话保持原规则。
3. **名单维护。**新增／编辑使用右侧表单，单个IPv4或IPv6必填、备注选填且最多200字；不接受CIDR、范围、通配符、协议或路径。同一名单按等价IP去重。普通新增默认停用，编辑保留状态和创建时间；手动记录提供编辑、启停、单条及批量删除，启停和删除须确认，取消或失败不部分写入。
4. **手动相互转换。**白名单提供转入黑名单，手动黑名单提供转入白名单；确认后原子移除来源并启用目标。目标不存在时新增并继承备注，已有目标时复用ID、备注及创建时间；成功进入目标页签并清空勾选。取消、无权限、来源／目标变化或保存失败不部分转换；已有临时黑名单须等待到期或提前解除。
5. **自动拉黑设置。**配置默认关闭，统计窗口（分钟）、累计失败次数（次）、拉黑时长（分钟）初始未设置；开启前均须为正整数，不预设建议值。密码错误和Google验证码错误两类均计入当前租户同一来源IP。配置独立保存回显，仅查看权限时只读；取消、参数非法、权限失效、配置变化或保存失败保留原配置。
6. **临时拉黑与恢复。**达到配置阈值后从原白名单转入临时黑名单，保存原ID、启用状态、备注及创建时间；到期退出临时黑名单并恢复原白名单。临时行仅提供提前解除，原因必填并确认后按同一规则恢复；白名单不再维护单独封锁状态。期间已有同IP白名单配置时保留当前配置，其他手动黑名单不被清除；原资料损坏或标识冲突继续拒绝，不擅自新增陌生IP准入。
7. **权限与审计（必做）。**同步维护页面菜单、查询、编辑、启停、删除、导出、转换、配置查看／修改和提前解除等按钮权限、接口鉴权及目标角色授权，核对存量运营角色；查看配置、修改配置和提前解除分别授权。配置变更、转入、自动触发、到期恢复及人工解除记录租户、IP、操作者／系统来源、时间、原因及结果，不记录密码和验证码内容。
8. **业务样例与交付验证。**原型直接展示白名单启停、IPv6、黑白重叠、到期／提前解除后恢复，以及手动黑名单启停、IPv6和有效临时拦截；黑名单展示来源、触发原因及到期时间，历史留在审计。原型已演示配置和预置临时记录恢复，真实登录失败自动计数、阈值触发及服务端调度仍须接入联调，不能以样例代替链路验收。

## 测试要验

1. 两页签入口归属正确；组合筛选、重置、分页、勾选及导出范围正确，切换不携带勾选，其他租户数据不可操作。
2. 启用白名单IP可继续认证；未知、停用、空名单和全部停用均拒绝。黑名单优先，停用或删除黑名单不能绕过白名单和其他认证；API及已有会话不变。
3. IPv4／IPv6、非法格式、CIDR、等价IP重复及200字备注校验有效；普通新增停用，编辑保留状态和创建时间，启停及删除取消或失败不改变原记录。
4. 手动两方向转换均移除来源并启用目标，新增／复用符合规则；取消、无权限、来源或目标变化时无部分写入，成功后页签、勾选及审计正确。
5. 自动配置首次关闭、三项参数空白，开启必填正整数；保存回显，取消或失败不变。只读账号无保存入口，配置提交前权限及快照变化能被拒绝。
6. 临时记录到期／提前解除后退出黑名单并恢复原白名单状态及资料；已有同IP新配置和其他手动黑名单不被覆盖。解除原因必填，无权限、取消、资料变化或恢复资料损坏时不部分恢复、不扩大准入；不能用通用编辑、启停、删除或批量操作绕过临时恢复。
7. 权限菜单和角色授权能配置所有新增能力，目标存量运营角色获授权后可用，未授权入口及接口受控。自动到期与人工解除日志可区分，日志不含密码、验证码。
8. 直接打开可查看完整样例；966px及常用桌面视口表单按钮可达，名单字段及操作可通过横向滚动查看。真实密码／Google失败计数、阈值触发及后台到期调度须单独联调验收。
