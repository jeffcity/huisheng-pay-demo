# 开发任务清单摘要

本次范围：租户端 → 系统管理 → 登录安全的自动拉黑设置与业务样例展示。

## 开发要做

1. 黑名单页签提供“自动拉黑设置”，点击打开右侧表单；白名单不显示该入口。工具栏显示自动拉黑开启／关闭状态。
2. 配置默认关闭，统计窗口（分钟）、累计失败次数（次）、拉黑时长（分钟）初始未设置；开启前均须填写大于0的整数，不预设10分钟／5次／30分钟。
3. 表单固定展示“密码错误”和“Google验证码错误”两类均计入的规则，统计范围为当前租户同一来源IP。当前交付配置与展示，登录失败自动计数、阈值触发及真实到期解除链路后续接入联调。
4. 配置按当前租户独立保存并回显；取消、参数非法、权限失效、配置已变化或保存失败时原配置不变。仅查看权限时表单只读，不显示保存按钮；保存成功记录审计。
5. 黑名单展示来源、触发原因和到期时间，支持直接查看手动启用、手动停用、IPv6、自动临时拦截、已到期和已解除等虚构业务样例；白名单配套展示启用、停用、IPv6、临时封锁和同IP黑白名单重叠。样例不预先开启自动拉黑，自动历史记录不代表当前规则已触发。
6. 原型和验收环境中的已到期、已解除样例不参与有效黑名单拦截；人工启用或转入已有自动记录时，确认转为长期有效的手动黑名单，保留ID、备注和创建时间，原自动信息写入审计；同IP手动黑名单仍独立生效，继续执行其他登录验证。API及已有会话保持原规则。
7. 权限同步（必做）：维护页面菜单、查询、编辑、转换及自动拉黑配置查看／修改等按钮权限、接口鉴权与目标角色授权，核对存量运营角色。配置查看和修改分别授权，后续人工解除也须登记对应权限；验收有权限可用、无权限受控。

## 测试要验

1. 黑名单有设置入口及状态，白名单无入口；首次关闭且三项参数为空，两种失败类型说明完整。
2. 开启时三项正整数必填，空值、0、负数、小数及非法字符无法保存；取消不保存，保存后重新打开正确回显。
3. 查看／修改分别授权，只读账号无保存按钮；授权失效、陈旧配置或保存失败不写入，审计不包含密码和验证码内容。
4. 直接打开即可看到两份名单的业务样例，来源、原因、创建时间、到期时间及状态对应正确；虚构样例可用于筛选、导出和行操作验证。
5. 启用手动和有效自动样例拦截新登录，停用、已到期及已解除样例不拦截；黑白重叠仍黑名单优先，白名单临时封锁不被转换或其他校验绕过，API与已有会话不变。
6. 在966px及常用桌面视口检查配置侧栏，输入、取消和保存可达；名单全部字段及操作可通过横向滚动查看。自动失败计数和真实触发、到期链路单独联调验收，不将配置保存或预置样例视为链路完成。
