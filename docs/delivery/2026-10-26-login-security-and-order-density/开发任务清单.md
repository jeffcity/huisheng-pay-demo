# 开发任务清单

适用范围：租户端 → 系统管理 → 登录安全，以及业务运营 → CNY代收订单、CNY代付订单。

白名单以现有开发页面为基线：https://saas-tenant-web1.newopsname.com/system/whitelist 。本期增加黑名单管理，并调整两张订单列表的显示密度。

## 开发要做

### 登录安全入口与列表

1. 在登录安全增加“白名单／黑名单”页签，分别展示和管理两份名单。
2. 白名单工具栏仅提供“新增白名单”；黑名单页签提供“新增黑名单”。已有白名单IP通过行内“转入黑名单”操作转换。
3. 黑名单提供IP地址、启用状态、备注、创建时间范围筛选，以及搜索、重置、导出、批量删除和分页。
4. 黑名单列表展示：勾选框、ID、IP地址、启用状态、拦截状态、来源、触发原因、到期时间、备注、创建时间、操作。手动条目启用时显示“拦截登录”，停用时显示“未生效”，提供编辑、删除、转入白名单和启停；有效临时条目显示临时拉黑，只提供提前解除。
5. 搜索后展示对应筛选结果；重置清空筛选并回到第一页。切换名单页签时清空勾选，操作、批量删除和导出均限定当前名单，导出使用已执行搜索的筛选范围。

### 黑名单新增、编辑与状态操作

1. 新增、编辑使用右侧表单，沿用白名单视觉：IP地址必填，备注选填，最多200字并显示字数。
2. IP支持单个IPv4或IPv6；不接受CIDR、IP范围、通配符、协议或路径。黑名单内相同IP不得重复新增，等价IPv6按同一地址判断。
3. 同一IP可以同时保存在白名单和黑名单中，两份记录分别维护。
4. 通过新增表单创建黑名单默认停用，保存后在列表回显，通过启用开关确认后生效。编辑保留原启用状态和创建时间；取消不保存，校验失败不部分更新。
5. 启用、停用、单条删除和批量删除均提供确认；取消或失败时原状态保留。记录发生变化时提示刷新重试，批量操作不部分生效。
6. 管理范围限定当前租户，操作沿用登录安全现有权限和审计要求。

### 黑白名单相互转换

1. 白名单每行显示“转入黑名单”；黑名单每行显示“转入白名单”。
2. 点击后弹窗展示目标IP、来源及目标名单，并说明确认后移除来源记录、启用目标记录。转入黑名单会拦截后台新登录；转入白名单会取消该条黑名单拦截并恢复白名单准入，仍须通过其他登录校验。两种操作均不影响API和已登录会话。
3. 确认后原子完成名单转换：目标名单没有该IP时新增启用记录并带入原备注；已有相同IP时复用原记录并启用，保留原ID、备注、创建时间及其他登录保护，不重复新增。
4. 来源记录无论启用或停用，都按转换确认结果启用目标记录；普通新增表单仍默认停用。
5. 成功后移除来源记录，切到目标名单展示结果，清空原勾选并记录对应转入审计。
6. 取消不修改名单；来源或目标记录变化、无权限或保存失败时，两份名单均不部分修改。

### 黑名单登录处理

1. 当前租户后台新登录优先检查已启用黑名单，命中即拒绝；即使该IP同时命中白名单，或当前没有启用的白名单，也拒绝本次登录。
2. 未命中有效黑名单时，必须精确命中启用白名单，随后执行账号、密码和Google验证码校验。白名单为空、全部停用、仅停用匹配或未知IP均拒绝，不提供无规则放行。
3. 停用或删除黑名单只取消对应拒绝规则；能否登录仍由其他校验决定。
4. 黑名单规则作用于租户后台新登录；业务API来源规则和已登录会话保持原状。手动规则独立于自动临时规则生效。

### 自动拉黑设置

1. 在黑名单页签工具栏提供“自动拉黑设置”，白名单页签不展示该入口；点击打开右侧配置表单。
2. 配置默认关闭，首次统计时间窗口、累计失败次数和拉黑时长未设置；不预填建议值。三个字段分别以分钟、次、分钟为单位，开启前均须填写大于0的整数。
3. 计入的失败类型固定展示“密码错误”和“Google验证码错误”，两者均计入当前租户同一来源IP的累计失败统计。
4. 支持保存和取消，保存后回显状态及参数；取消、校验失败、权限失效、配置已变化或保存失败时保留原配置。仅有查看权限时表单只读，不显示保存按钮。
5. 规则开启后，同一来源IP在配置时间窗口内累计失败达到阈值，生成自动临时拉黑记录；记录区分自动触发与手动维护，并展示触发原因、拉黑时间和到期时间。
6. 自动临时拉黑从原启用白名单转出并保存原资料；到期从临时黑名单退出并恢复原白名单及原状态、备注、ID和创建时间。期间同IP已有白名单配置时保留当前配置；原资料不可用时继续拒绝并提示核对。不取消同IP手动黑名单，不改变API和已有会话。
7. 临时黑名单提供提前解除，原因必填并二次确认；确认后按相同规则恢复白名单。白名单不再单独维护封锁状态或解除封锁按钮；临时记录不使用普通编辑、启停、删除及永久转换。
8. 配置保存与后续自动触发、到期解除、人工解除均记录审计，包含对应租户、对象、动作、操作人或系统来源、结果和时间，不记录密码或验证码内容。

### 原型与验收业务样例

1. 白名单展示启用、停用、IPv6、黑白重叠及临时黑名单到期／提前解除后恢复的记录；到期和已解除的过程留在审计，当前黑名单不残留失效条目。
2. 黑名单展示手动启用、手动停用、IPv6、有效自动临时拦截；标注来源、触发原因及到期时间。手动记录长期有效，自动记录到期恢复原白名单。
3. 样例为虚构业务状态，当前配置仍默认关闭、参数未设置；示例阈值不作为默认值。原型演示已有临时记录的恢复，真实失败计数和阈值触发链路后续独立联调。

### 权限维护

1. 同步维护登录安全页面菜单、黑白名单按钮权限及对应接口鉴权；在角色授权配置中登记自动拉黑设置的查看、修改及后续人工解除权限，核对新增或复用关系和目标角色授权。
2. Demo中配置查看与修改使用独立权限点；正式权限编码由开发按现有项目核对，不以界面可见代替接口鉴权，也不默认对所有运营角色开放。
3. 覆盖目标存量角色的授权配置，验收有权限账号可正常查看及保存、无权限账号隐藏或禁用入口且接口拒绝；授权失效时不部分写入。

### CNY代收、代付订单列表

1. 分别收窄两页表格列宽与单元格留白，短字段使用较窄宽度；代付勾选列单独收窄，避免与订单号使用相同宽度。
2. 保留现有全部栏位、顺序、内容、复制和行操作，不通过隐藏字段减少表格宽度。
3. 长订单号、通道名称和时间允许合理换行；编号保留全文，复制结果保持完整，金额和状态清晰可读。
4. 小屏幕一次展示更多栏位；超出内容区时保留横向滚动，不能因压缩导致文字重叠或按钮无法操作。
5. 当前Demo的紧凑表格总宽参考：代收约1070px，代付约1134px。按可用内容区响应式适配；966px视口是验收场景之一，不作为唯一断点。
6. 本次密度样式只作用于这两张订单表；订单查询、筛选、金额统计、导出字段和业务操作结果保持原规则。

## 测试要验

### 登录安全入口与名单操作

1. 白名单工具栏显示“新增白名单”，不显示“新增黑名单”；切到黑名单后显示“新增黑名单”，保存后展示新记录，白名单原记录不改变。
2. 各项筛选可组合生效；重置恢复全部结果及第一页，切换名单不会携带勾选误操作另一份名单。
3. 新增保存后为停用，启用后显示“拦截登录”；编辑回填IP和备注，保留启用状态及创建时间。
4. 空IP、非法地址、CIDR、重复IP、等价IPv6重复及超过200字备注不能保存；有效IPv4/IPv6可以保存。
5. 编辑、启停、删除和批量删除取消后保留原数据；确认仅影响所选名单和记录。陈旧记录或失败时不部分写入。
6. 分页、全选、导出及批量删除作用范围正确；其他租户数据不可查看或修改，操作审计可追溯。

### 名单转换

1. 从启用和停用的白名单分别转入黑名单，来源记录被移除，目标均启用，命中后拒绝后台新登录。
2. 从黑名单转入白名单，来源黑名单移除且目标白名单启用；新登录继续执行其他验证，不能绕过密码、Google验证码或既有登录保护。
3. 目标不存在时继承原备注；已存在时复用原记录，ID、备注和创建时间保留，不出现重复IP。
4. 两种方向均验证取消、来源变化、目标变化、无权限和失败；不能部分转换，也不影响其他记录。
5. 成功后进入目标名单页签，原勾选不残留，审计可以识别方向；API和已登录会话不受影响。

### 黑名单登录结果

1. 同一IP同时在两份已启用名单内，新登录被黑名单拒绝。
2. 没有启用白名单时，命中已启用黑名单仍被拒绝。
3. 黑名单停用或删除后，重新按原登录规则校验；不能绕过白名单、密码或Google验证码。
4. 启用黑名单前已建立的会话继续保持，业务API行为不因本次黑名单操作改变。

### 自动拉黑配置与登录结果

1. 黑名单有配置入口，白名单无入口；首次关闭、三参数空白，开启时三项正整数必填；保存回显，取消和失败不变。
2. 仅启用白名单IP可进入认证；空名单、全停用、未知或停用匹配均拒绝。密码和Google错误计入规则，真实计数及阈值触发另行联调。
3. 预置临时记录到期或提前解除后从黑名单移除，原白名单资料和原状态保留；期间已有同IP白名单的配置不被覆盖，其他手动黑名单独立有效。
4. 提前解除原因和权限有效；取消、权限撤销、来源或目标变化时不部分写入。恢复资料异常时不扩大准入，系统到期与人工解除均可追溯审计。
5. 白名单无单独封锁状态和解除入口；临时黑名单不参与通用启停、编辑、删除及批量删除，提前解除使用单独权限。
6. 权限菜单和角色授权能找到新增配置查看／修改／提前解除能力；目标角色获授权后可用，无权限受控。日志不含密码、验证码，API和已有会话不变。

### 订单列表

1. 在966px及常用桌面视口检查两页，能看到更多完整栏位，表头与内容对齐，无文字、金额或按钮重叠。
2. 代收11栏、代付13栏均保留；长编号可完整查看，复制结果与完整编号一致。
3. 长内容合理换行，勾选、详情、更多、补单等原有操作仍可使用，横向滚动可以到达全部栏位。
4. 调整前后同一条件下的订单数据、筛选结果、统计金额和导出字段一致；其他页面表格密度不受影响。
