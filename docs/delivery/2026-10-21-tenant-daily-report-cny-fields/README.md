# 租户端日终统计CNY栏位

运营中心四张日终统计仅展示CNY。两张通道报表展示服务费与利润，不展示代理费；商户代收展示商户服务费及通道服务费，商户代付展示商户服务费；两张商户报表均展示初期预付、末期预付及数值型预付明细，并保留钱包期初、期末余额，不展示钱包明细列或弹窗。

- [需求说明](需求说明.md)
- [统一Demo评审入口](https://jeffcity.github.io/huisheng-pay-demo/)：租户端 → 运营中心 → 对应日终统计。

本目录为GitHub只读交付快照，活动需求位于产品需求文件夹的“2026-10-21-日终统计CNY栏位调整”。费用、利润、预付及统计取值沿用蓝盛现有代码逻辑；Demo使用合成样例，不代表真实后端或资金接入。
