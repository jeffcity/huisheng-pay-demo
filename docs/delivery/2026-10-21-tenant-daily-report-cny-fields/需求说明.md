# 租户端日终统计CNY栏位调整

## 需求说明

租户端运营中心四张日终统计以蓝盛对应报表为参照，展示CNY交易、费用和预付信息。各报表保留独立入口，不展示序号。

## 页面栏位

| 页面 | 本期展示栏位（按列表顺序） |
| --- | --- |
| 代付通道日终统计 | 日期、商户号、商户名称、通道名称、成交金额、总单量、成交率、服务费、利润、备注 |
| 代收通道日终统计 | 日期、商户号、商户名称、通道名称、成交金额、总单量、成交率、服务费、利润、备注 |
| 商户代收日终统计 | 日期、商户名称、成交金额、总单量、成功数、成交率、商户服务费、通道服务费、代收钱包期初余额、代收钱包期末余额、初期预付、末期预付、预付明细 |
| 商户代付日终统计 | 日期、商户名称、订单总金额、成交金额、未成交金额、总单量、成功数、未支付、成交率、商户服务费、代付钱包期初余额、代付钱包期末余额、初期预付、末期预付、预付明细 |

## 页面行为与验收

1. 四页币种页签仅保留CNY，查询、重置、分页、合计与导出均为当前租户CNY数据，不展示其他币种记录或USDT余额/预付栏位。
2. 通道报表展示服务费和利润；不展示代理费，导出也不含代理费。利润可展示负数、费用可展示零值；金额保留两位小数。
3. 商户代收展示商户服务费及通道服务费；商户代付只展示商户服务费。两页均展示初期预付、末期预付和数值型预付明细。预付值与钱包余额独立，不互相替代。
4. 两张商户日终统计均不展示钱包明细列、查看按钮或对应弹窗；列表保留钱包期初、期末余额。预付明细仍按蓝盛列表数值呈现。
5. 表格可横向滚动查看全部栏位；合计对当前筛选的完整结果汇总成交金额、订单数量及对应费用/利润，不随分页变化。期初期末余额与预付快照不跨记录累加。
6. 导出包含当前筛选的全部CNY记录及已保存备注，字段顺序与列表一致，预付明细数值保留；空结果禁用导出。
7. 通道备注的编辑、保存、取消及清空继续生效，按既有记录维度隔离。
8. 正式数据取值、费用、利润、预付及统计口径沿用蓝盛现有代码逻辑，不从Demo样例推导公式。Demo仅使用合成样例，不改真实账务、钱包或资金。
