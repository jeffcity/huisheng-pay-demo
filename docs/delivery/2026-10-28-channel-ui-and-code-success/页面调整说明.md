# 通道与产品页面调整

## 开发要做

1. 代收通道管理、代付通道管理、代收产品管理、代付产品管理沿用当前开发环境的说明条、筛选区、操作栏和列表结构。编辑及绑定窗口按页面字段展示，数据与操作维持租户隔离。
2. 通道名称放大并加粗，金额适度加粗，通道商、备注和单位用常规字重。表头保持统一层级。
3. 代收通道展示CNY资金列，子编码勾选独立成列；编码与备注同行，费率输入与修改操作收紧，多编码行44px。父通道资料按合并单元格展示。
4. 代付通道统一16列表头和行操作；权重、通道费率及单笔费用用数字输入。资金菜单与一键结算继续本地预览，限额及开发窗口未展示的既有配置保留。
5. 两类产品按名称和编码查询；代收产品另可按状态查询。产品表按字段分配窄列，数量、状态及勾选列收紧，行操作同行，普通行高44px。
6. 产品绑定通道提供范围输入／保存及权重输入；绑定商户展示商户名称、商户号、费率、代理费率、单笔手续费、已绑通道数和配置开关。修改仍复验当前租户与对应通道业务授权。
7. 同步维护菜单、按钮及接口权限与运营角色授权，验证有权可用、无权不可执行；权限标识按现有目录核定，不自造标识或默认全员授权。

## 测试要验

1. 四页可由统一导航进入，查询、重置、分页和新增／编辑入口可用。
2. 长名称和编码完整展示，列内操作不被裁切；小屏在表格内滚动，页面自身不溢出。
3. 费率编辑、确认／回车、取消和非法数值提示正常，拒绝越权或跨租户保存。
4. 隐藏的旧限额配置保存后不被清空，产品绑定和删除沿用既有规则。
5. 资金操作及通道测试只生成本地演示结果，不改变实际资金或发送真实支付请求。
