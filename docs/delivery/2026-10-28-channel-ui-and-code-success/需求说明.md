# 代收编码成交成功率展示

## 页面与展示

租户端 → 通道管理 → 代收通道管理，在每个子编码的“今日成交”单元格内增加今日成功率，展示为“86（95.6%）”，成交值在前，成功率在括号中。沿用原表头与紧凑行高，不增加独立列。

成功率使用当前租户、当前子编码自身的今日统计数据；不使用父通道成功率代替，不将不同编码或不同租户合并。统计日期范围及公式读取既有后端定义，本次不定义新分母或订单状态口径。

没有成交且没有成功率时显示“0”；已有成交但成功率未提供时显示“86（—）”。实际返回0%时展示0%，未知值不能当作0%。复制或新增编码不沿用原编码的历史成功率。

## Demo范围

为现有子编码补充独立模拟百分比，按当前页面直接展示。未接入开发环境接口或修改真实订单统计。父通道资金、费率、编码绑定及下单逻辑不调整。

## 开发核对

将成功率纳入当前页面查询及租户、编码数据范围校验。沿用本页菜单与查询权限，核对接口鉴权及运营角色授权；有权限可查看对应租户的数据，无权限不可读取统计。无新增独立按钮权限，不自造权限标识。

## 测试要验

- 不同子编码显示各自成交值及成功率；0%、100%正常显示。
- 无数据、缺失成功率与真实0%按上述方式区分。
- 切换租户、搜索及翻页后对应记录不串数据；统计周期沿用现有后台口径。
- 成交值与百分比同格同行，44px多编码行不被撑高，原费率编辑与操作入口正常。
