# 代付调额取消谷歌验证——开发任务清单

1. **以下三个入口都不再要求谷歌验证：**
   - 「代付通道管理」→ 余额调整。
   - 「已授权通道商 → 代付」→ 余额调整。
   - 「已授权通道商 → 代付」→ 总预付调整。

2. **移除验证码输入和校验。**
   - 删除“谷歌验证”输入框及相关提示。
   - 提交时不再传验证码，后端也不再要求验证。
   - 重置、关闭、重新打开弹窗均可正常使用。

3. **保留原有调额规则。**
   - 保留增加／减少、金额、备注和原有金额检查。
   - 从通道商入口调整余额时，仍须选择具体代付通道。
   - 调整后，通道余额与通道商汇总余额保持一致。
   - 总预付沿用原有计算规则；重复点击不能重复调额。

4. **权限和操作记录一起检查。**
   - 保留菜单、调额按钮权限、后端权限校验及现有角色授权。
   - 只能调整当前租户有权操作的数据。
   - 操作记录保留操作人、时间、对象、调整前金额、本次增减、调整后金额和备注。
   - 其他操作及登录的谷歌验证保持原样。

**测试要验**

- 三个入口都能不填验证码完成调额。
- 金额无效、减少金额超过允许额度时，不能提交。
- 通道商余额调整未选通道时，不能提交。
- 调整结果、汇总金额及操作记录一致，重复提交不会重复生效。
- 无权限账号、跨租户请求不能调额。
