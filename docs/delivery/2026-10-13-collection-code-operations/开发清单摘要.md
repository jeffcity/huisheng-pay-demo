# 代收通道管理开发清单摘要

当前入口：租户端 → 通道管理 → 代收通道管理。页面及字段按最新 Demo，操作前及保存时校验本租户对应通道商的代收授权。

## 开发要做

1. 租户端「代收通道管理」每个编码的「更多」菜单增加修改通道编码、单独对接信息、删除通道编码，保留原出码测试。
2. 修改备注、费率、金额范围和通道编码，备注与编码必填；保存后更新列表，原单独对接配置保留。
3. 单独对接提供商户号、密钥、下单地址、查询地址、回调IP、公钥、私钥；前五项必填，按编码独立保存，关闭不保存。
4. 每个编码可单独勾选，支持全选当前列表及批量删除；显示已选数量，未选择时按钮不可用，筛选及切页不带入隐藏选择。
5. 单条和批量删除都先确认目标，只删除选中的编码及对应配置，保留通道、其他编码、历史订单与资金数据。开发复用蓝盛现有代码，适配汇盛权限和数据范围。

## 测试要验

1. 回填、必填校验、保存和关闭不保存正常。
2. 修改编码后配置保留，出码测试使用新编码，不串用其他编码配置。
3. 删除取消不变，确认只删目标；最后一个编码删除后通道和资金仍保留。
4. 批量选择数量与确认目标一致，筛选和切页不误删隐藏记录，权限及数据范围校验有效。

Demo仅演示当前页面的交互与状态；真实接口、后端校验及生效逻辑需迁移蓝盛代码后联调。
