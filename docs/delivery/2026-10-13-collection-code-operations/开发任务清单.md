# 代收通道编码操作

当前入口：租户端 → 通道管理 → 代收通道管理。页面及字段按最新 Demo，操作前及保存时校验本租户对应通道商的代收授权。

## 开发要做

### 编码操作入口

1. 租户端「代收通道管理」每个对接编码的「更多」菜单依次提供「修改通道编码」「出码测试」「单独对接信息」「删除通道编码」。

### 修改通道编码

1. 弹窗按蓝盛展示「备注」「费率」「金额范围」「通道编码」，备注和通道编码必填。费率提示「使用小数，0.01代表1%」，金额范围用-隔开，通道编码提示「三方通道编码」。
2. 打开回填当前记录；保存更新对应编码、备注、费率及收款规则。关闭不保存当前输入。
3. 修改编码后，原记录的单独对接信息继续保留，不串用其他编码配置。

### 单独对接信息

1. 展示商户号、密钥、下单地址、查询地址、回调IP、公钥、私钥，前五项必填，公钥私钥选填。
2. 「保存」只更新当前编码，再次打开回填；「关闭」不保存当前输入。

### 删除通道编码

1. 点击后显示「确定要删除通道编码【当前编码】吗？」，提供「取消」「确定」及关闭入口。
2. 取消或关闭不删除；确定后移除当前通道的该编码及对应独立配置，不删除通道主体、其他编码或历史订单与资金记录。
3. 删除最后一个编码后保留通道行，对接编码、今日成交、费率、收款规则、类型状态和编码操作显示-。

### 批量删除通道编码

1. 在每个对接编码旁增加勾选框；表头全选只选择当前列表编码，原通道勾选框不用于删除编码。
2. 工具栏增加「批量删除通道编码」及已选数量；未选编码时按钮不可用。
3. 确认框列出所选通道和编码，取消或关闭保留选择与记录；确定只删除列表中选中的编码及其独立配置。
4. 筛选后不保留隐藏编码的选择，切换页面清空选择；删除后清除已删编码选择，通道、未选编码与资金记录保留。

### 复用与边界

1. 复用蓝盛现有字段、保存与删除接口、后端校验和业务生效逻辑，适配汇盛通道、编码和现有操作权限及数据范围。
2. 开发从蓝盛源码核对编码唯一性、费率/金额范围校验及删除前置条件，不仅移植前端弹窗。
3. 保存或删除失败时保留原配置和记录并提示失败原因；密钥与私钥不进入列表、导出或审计正文。

## 测试要验

1. 修改回填正确；备注或编码为空不能保存，关闭未保存修改后仍为原记录；保存后仅目标编码栏位更新。
2. 修改编码后原单独对接信息仍回填，其他编码配置不变；原出码测试使用修改后的编码。
3. 删除确认正确标出目标编码；取消不变，确定只删目标记录；删除最后一个编码保留通道行及资金数据。
4. 单独对接信息必填校验、按编码保存和关闭不保存正常；代付页面没有这些代收编码操作。
5. 无对应权限或超出数据范围不能修改、保存、删除；日志与导出不包含密钥私钥。真实后端校验及生效需开发迁移后联调。

6. 批量勾选、全选当前列表、已选数量和按钮状态一致；取消不删除，确定只删除所选编码，筛选及切页不带入隐藏选择，其他编码和通道资金数据不变。
