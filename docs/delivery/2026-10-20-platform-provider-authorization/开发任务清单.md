# 平台端通道商授权开发任务清单

## 开发要做

| 功能 | 开发任务与规则 |
|---|---|
| 按租户管理 | 先选择有权管理的租户，再加载授权清单；未选择时显示引导。本页不展示租户服务费，收费设置由租户管理维护。 |
| 通道商清单 | 展示平台全部已接入通道商，包括已授权和未授权；字段为通道商名称／编号、支持业务、代收授权、代付授权、授权状态、最近变更。 |
| 搜索与筛选 | 支持名称／编号搜索，以及已授权／未授权筛选；按已保存授权筛选。重置只清空查询条件，保留当前租户和未保存修改。 |
| 快速勾选 | 列表直接勾选或取消代收／代付方向，不支持的方向不可操作；修改行及顶部显示待保存状态。草稿跨搜索、筛选保留，支持撤销；有未保存修改时，切换租户或刷新须先确认是否放弃。 |
| 统一保存 | 汇总全部修改的授权前后值，填写变更原因并验证当前操作人Google MFA后提交。提交前复验管理权限、租户范围、所选租户、通道商接入状态、支持方向及原授权；任一失败整批不写入。全部方向取消时停用授权并保留记录；未修改通道商及其他租户不受影响。验证码不保存。 |
| 导出授权 | 导出当前租户及筛选范围内的已保存授权，包含未授权通道商，不导出未提交勾选；仅有导出权限的账号可操作。 |

## 测试要验

| 场景 | 预期结果 |
|---|---|
| 未选租户、选择有管理范围的租户 | 初始显示引导；选择后显示全部已接入通道商，授权状态属于所选租户，不展示服务费。 |
| 勾选后搜索、切换筛选及重置 | 草稿保留、待保存数量准确；按已保存状态筛选，未提交勾选不导致当前行突然消失。 |
| 多个通道商同时变更，包含首次授权和取消全部方向 | 确认页列出全部修改；成功后回显，全部方向取消后授权停用，其他通道商及租户保持原值。 |
| 原因或验证码无效；提交前权限、租户、支持方向或原授权变化 | 整批拒绝且原授权不变；取消提交保留草稿，关闭或成功提交后验证码清空。 |
| 有草稿时切换租户、刷新或撤销修改 | 取消切换时继续原租户编辑；确认放弃后载入目标租户或最新授权；撤销恢复已保存状态。 |
| 只读权限、导出及窄屏操作 | 只读账号不能修改或保存，无导出权限不能导出；导出不含草稿；窄屏表格可横向滚动，确认弹窗不超出屏幕。 |
