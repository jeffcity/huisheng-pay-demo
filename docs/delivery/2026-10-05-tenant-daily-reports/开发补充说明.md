# 开发补充说明

关联：[PRD_租户端日终统计报表_20261005](PRD_%E7%A7%9F%E6%88%B7%E7%AB%AF%E6%97%A5%E7%BB%88%E7%BB%9F%E8%AE%A1%E6%8A%A5%E8%A1%A8_20261005.md)、[开发任务清单](%E5%BC%80%E5%8F%91%E4%BB%BB%E5%8A%A1%E6%B8%85%E5%8D%95.md)。

## 交易统计

- 对应蓝盛四页逐页移植，不将通道统计与商户统计视为可以任意互换的汇总。
- 成交率的分母、未支付／未成交的状态集合及金额计算，以蓝盛对应代码为依据；不在本需求中另设新算法。
- 不假定“未支付 = 总单量 − 成功数”或“钱包变动 = 成交金额”，也不由 Demo 样例建立此类生产规则。
- 统计日期按 UTC+8 展示。需核对蓝盛订单日期归属逻辑与汇盛字段映射，不能直接按页面标签猜测日期字段。

## 币种与合计

- 四页各自按当前租户有效币种建立 Tab；CNY、USD、PHP、THB 为本地交互样例，不是正式启用清单。
- 正式币种清单、初始币种及金额精度来自租户当前配置与既有规则。
- 币种切换不换汇；每一币种的记录数、合计、钱包和导出独立计算。
- 合计只累加同一筛选范围内允许相加的金额和单量；钱包期初／期末跨日期相加没有业务意义，成交率不累加。
- 删除费用展示不等于取消计费或账变；实际费用仍按既有业务入账，并影响真实钱包快照。

## 商户钱包

- 所有者是行内商户，不是当前租户的平台钱包；币种和钱包类型必须与所点记录一致。
- 商户代收页读取代收钱包；商户代付页读取代付钱包，不增加提款钱包列。
- 列表期初、期末均为钱包总额。冻结和可用放入只读钱包明细。
- 历史期末冻结及可用必须与历史期末总额对应同一时点；今日使用实际截至快照。
- 钱包余额包含所有已记账业务，不能仅从报表成交金额计算。
- 本期不要求从历史钱包明细发起当日流水查看、资金更正、划转或订单处理。

## 备注持久化

- 备注归属为：当前租户、代收／代付方向、币种、统计日期、商户、通道。
- 商户或通道名称变更不应导致备注与记录脱离；研发使用稳定业务标识关联。
- 列表位置、页码、排序或显示序号不能作为备注身份。
- 统计刷新与重新生成结果不覆盖人工已保存备注。
- Demo 使用浏览器本地保存，仅用于评审；正式实现需接入服务端持久化和记录归属校验。
- 正式长度约束、角色授权与多人同时编辑策略按既有规范核对；缺少既有规则时提出确认，不由样例代码决定。

## 入口退出

- 运营中心提供四个报表入口，原经营报表与资金中心日终报表不再呈现在当前导航或快捷链接。
- 历史地址不能重新打开退出页面；当前 Demo 的资金日终历史地址回总览，仅作为路由兜底示例。
- 入口退出不删除历史数据，也不更改其他资金页面的职责。

## Demo 与真实开发

| 项目 | Demo 表现 | 正式实现 |
|---|---|---|
| 数据 | 静态交互样例 | 蓝盛计算映射至汇盛真实统计 |
| 币种 | 四个交互示例 | 当前租户有效币种及既有默认、精度规则 |
| 日期／截至时间 | 固定演示日期与时间 | UTC+8 查询范围及实际数据截至时间 |
| 钱包 | 展示示例快照 | 对应商户、币种、钱包类型的真实快照 |
| 备注 | 浏览器本地保存 | 服务端持久化、授权与归属校验 |
| 导出 | CSV 交互示例 | 现有报表格式、容量及安全规范，完整筛选范围 |
