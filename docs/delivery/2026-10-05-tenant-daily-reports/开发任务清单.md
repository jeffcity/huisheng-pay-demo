# 租户端日终统计报表开发任务清单

依据：[PRD_租户端日终统计报表_20261005](PRD_%E7%A7%9F%E6%88%B7%E7%AB%AF%E6%97%A5%E7%BB%88%E7%BB%9F%E8%AE%A1%E6%8A%A5%E8%A1%A8_20261005.md)、[开发补充说明](%E5%BC%80%E5%8F%91%E8%A1%A5%E5%85%85%E8%AF%B4%E6%98%8E.md)。交互参考：[统一 Demo](https://jeffcity.github.io/huisheng-pay-demo/#tenant) → 租户端 → 运营中心。

## 开发要做

### 入口与页面导航

- [ ] 在租户端运营中心注册“代付通道日终统计”独立入口，进入后显示对应标题与当前位置。
- [ ] 在租户端运营中心注册“代收通道日终统计”独立入口，进入后显示对应标题与当前位置。
- [ ] 在租户端运营中心注册“商户代收日终统计”独立入口，进入后显示对应标题与当前位置。
- [ ] 在租户端运营中心注册“商户代付日终统计”独立入口，进入后显示对应标题与当前位置。
- [ ] 移除运营中心原经营报表的当前菜单、快捷入口和可打开原页面的内部链接。
- [ ] 移除资金中心日终报表的当前菜单、快捷入口和可打开原页面的内部链接。
- [ ] 同步租户端页面权限目录；历史地址使用有效页面兜底，不能重新打开退出页面。
- [ ] 保持平台端、商户端及其他资金功能入口的业务归属。

### 代付通道日终统计

- [ ] 按顺序展示：日期、商户号、商户名称、通道名称、成交金额、总单量、成交率、备注。
- [ ] 通道筛选展示“全部渠道”及当前租户对应代付方向可查询通道。
- [ ] 按当前租户、代付方向、币种、统计日期、商户和通道返回独立记录，日期倒序展示。
- [ ] 对接蓝盛代付通道对应的成交金额、总单量、成交率计算与日期口径。
- [ ] 在每条明细的备注单元格提供“编辑”；合计行不提供备注编辑。
- [ ] 本页不显示序号、服务费、代理费、利润。

### 代收通道日终统计

- [ ] 按顺序展示：日期、商户号、商户名称、通道名称、成交金额、总单量、成交率、备注。
- [ ] 通道筛选展示“全部渠道”及当前租户对应代收方向可查询通道。
- [ ] 按当前租户、代收方向、币种、统计日期、商户和通道返回独立记录，日期倒序展示。
- [ ] 对接蓝盛代收通道对应的成交金额、总单量、成交率计算与日期口径。
- [ ] 在每条明细的备注单元格提供“编辑”；合计行不提供备注编辑。
- [ ] 本页不显示序号、服务费、代理费、利润。

### 商户代收日终统计

- [ ] 按顺序展示：日期、商户名称、成交金额、总单量、成功数、成交率、代收钱包期初余额、代收钱包期末余额、钱包明细。
- [ ] 商户筛选展示“全部商户”及当前租户所属商户。
- [ ] 按当前租户、代收方向、币种、统计日期和商户返回独立记录，日期倒序展示。
- [ ] 对接蓝盛商户代收对应交易指标和日期口径。
- [ ] 列表钱包余额读取该商户、该币种代收钱包的总额快照。
- [ ] 点击行内“钱包明细”打开当前页只读弹窗，按该行归属读取内容。
- [ ] 本页不显示序号、商户服务费、通道服务费，也不增加备注列。

### 商户代付日终统计

- [ ] 按顺序展示：日期、商户名称、订单总金额、成交金额、未成交金额、总单量、成功数、未支付、成交率、代付钱包期初余额、代付钱包期末余额、钱包明细。
- [ ] 商户筛选展示“全部商户”及当前租户所属商户。
- [ ] 按当前租户、代付方向、币种、统计日期和商户返回独立记录，日期倒序展示。
- [ ] 对接蓝盛商户代付对应交易指标和日期口径；“未支付”按单量显示，不按金额格式显示。
- [ ] 列表钱包余额读取该商户、该币种代付钱包的总额快照。
- [ ] 点击行内“钱包明细”打开当前页只读弹窗，按该行归属读取内容。
- [ ] 本页不显示序号、商户服务费、通道服务费，也不增加备注列。

### 四页共用币种 Tab 与查询

- [ ] 根据当前租户有效币种生成独立 Tab；默认币种沿用既有租户端规则，不硬编码 Demo 四币种为正式授权清单。
- [ ] 币种 Tab 取代币种下拉筛选，不提供跨币种总览或合计。
- [ ] 切币种保留已应用的商户／通道、日期条件，加载目标币种第 1 页。
- [ ] 查询返回的记录数、金额、钱包明细及合计均明确属于当前币种。
- [ ] 提供统计时间“全部时间、今天、昨天、本周、本月”及开始／结束日期输入，日期按 UTC+8 计算。
- [ ] 点“搜索”才应用筛选输入并回第 1 页；未应用输入不修改当前结果和导出条件。
- [ ] 开始日期晚于结束日期时阻止请求并提示，保留原已应用结果。
- [ ] 点“重置”清空商户／通道和日期，恢复全部时间并回第 1 页，保留当前币种。
- [ ] 无数据时显示空态和零条记录，禁用导出；查询失败时显示可重试提示，不伪装为零条。
- [ ] 处理快速切 Tab 或修改查询时的迟到响应，仅展示当前有效查询结果。
- [ ] 记录数显示完整已应用筛选结果数量；展示真实数据截至时间。

### 四页共用分页与合计

- [ ] 默认 10 条／页，提供 20、50 条／页；修改每页条数回第 1 页。
- [ ] 提供上一页、下一页、页码选择及指定页码跳转；非法页码提示并保留当前页。
- [ ] 合计覆盖当前币种和完整已应用筛选结果，翻页不改变合计范围。
- [ ] 通道页合计成交金额、总单量；日期列显示“合计”，其他不合计字段显示“—”。
- [ ] 商户代收页合计成交金额、总单量、成功数；钱包余额与成交率不求和。
- [ ] 商户代付页合计订单总金额、成交金额、未成交金额、总单量、成功数、未支付；钱包余额与成交率不求和。
- [ ] 金额按对应币种现有精度展示和汇总，不能先截断显示再求和，不能进行跨币种换算。

### 通道备注编辑弹窗与保存

- [ ] “编辑”打开备注弹窗，展示该行日期、商户名称／商户号、通道及币种。
- [ ] 回填该条已保存备注，提供文本输入框、“保存”“取消”和关闭图标。
- [ ] 支持换行文本；空备注在列表显示“—”，仍允许编辑。
- [ ] 按租户、方向、币种、日期、商户和通道识别记录，正式存储不能只靠列表行号或浏览器本地存储。
- [ ] “保存”成功后关闭弹窗、更新该行备注并提示成功，不改变交易指标和钱包金额。
- [ ] 空文本保存清空该条备注，列表恢复“—”。
- [ ] 取消、关闭图标或 Esc 关闭不提交，原保存内容保持不变。
- [ ] 保存失败保留原已保存值和输入草稿，不关闭弹窗或显示成功，允许重试。
- [ ] 已保存备注在筛选、翻页、切币种、刷新或重新进入后仍可读取。
- [ ] 统计结果重新生成时保留该业务记录的已保存备注。
- [ ] 前后端接入既有报表备注操作授权，保存时核对当前租户记录归属，不因本期入口自动开放给全部角色。
- [ ] 文本展示及导出按安全文本处理；长度和并发覆盖策略沿用既有规范，无规范时提出确认。

### 商户钱包明细弹窗

- [ ] 标题显示代收／代付钱包类型；识别区展示商户名称／商户号、日期和币种。
- [ ] 展示期初余额、期末余额、期末冻结金额、期末可用余额四项金额。
- [ ] 期初为 UTC+8 自然日开始的总额；历史期末为该自然日结束的总额；今日为实际查询截至总额。
- [ ] 冻结与可用按期末同一时点取得，可用等于期末总额减期末冻结金额。
- [ ] 今日显示真实截至时间；历史快照不得使用当前实时余额代替。
- [ ] 提供“关闭”、关闭图标和 Esc 返回原筛选与页码，保持列表位置。
- [ ] 弹窗只读，不提供当日流水、钱包或订单跳转，不提供资金调整或划转操作。
- [ ] 快照查询失败显示失败并允许重试，不填造零余额。

### 四页共用导出

- [ ] “导出”使用当前币种和已应用筛选条件，覆盖全部分页，不能仅导出页面现有行。
- [ ] 导出字段与本页表格一致，不含序号、删除的费用字段或“钱包明细”按钮。
- [ ] 两个通道页导出已保存备注，弹窗尚未保存的草稿不进入文件。
- [ ] 导出完整筛选合计，与列表合计保持一致；文件名称可识别报表及币种。
- [ ] 引号、换行、分隔符及公式前缀按安全文本处理，金额保持对应币种精度。
- [ ] 接入现有报表导出权限、文件格式与容量规范；失败提示并允许重试，不显示导出完成。

### 数据接入与交付核对

- [ ] 逐页记录蓝盛指标计算代码位置及汇盛字段映射；核对成交率分母和未支付／未成交状态集合，不另造业务公式。
- [ ] 核对蓝盛统计日期归属与汇盛 UTC+8 日期映射；存在冲突时说明影响后确认，不能无依据改口径。
- [ ] 核对商户钱包历史／今日快照来源及截至时点，保证所查钱包的商户、币种、类型一致。
- [ ] 所有查询、备注和导出在服务端校验租户、币种与权限，拒绝未授权记录。
- [ ] 备注及导出接入既有审计规则；不为只读查询或备注更新生成资金流水。
- [ ] 提供四页蓝盛统计对照样本、商户钱包快照样本及备注正式持久化验证结果。

## 测试要验

### 入口与页面导航

- [ ] 从运营中心分别点四个页面，标题、当前位置和表格类型与菜单名称一致。
- [ ] 检查当前菜单、快捷入口、权限目录和内部链接，原经营报表及资金中心日终报表不可打开。
- [ ] 访问退出页面历史地址，进入有效兜底页面或提示，不呈现退出页面数据。
- [ ] 查看其他端和其他资金入口，入口归属及原业务操作不因报表调整改变。

### 代付通道日终统计

- [ ] 进入本页，8 列及顺序与 PRD 4.1 一致；无序号与三项费用／利润字段。
- [ ] 选某代付通道搜索，每行属于该通道和当前币种，结果不含代收方向。
- [ ] 按租户、币种、日期、商户与通道对照蓝盛样本，成交金额、总单量和成交率一致。
- [ ] 同日同商户不同通道分别出现独立记录，每行有“编辑”，合计行无“编辑”。

### 代收通道日终统计

- [ ] 进入本页，8 列及顺序与 PRD 4.2 一致；无序号与三项费用／利润字段。
- [ ] 选某代收通道搜索，每行属于该通道和当前币种，结果不含代付方向。
- [ ] 对照蓝盛代收通道样本，成交金额、总单量和成交率一致。
- [ ] 查询失败或无数据分别出现失败提示或空态，两种情况可区分。

### 商户代收日终统计

- [ ] 进入本页，9 列及顺序与 PRD 4.3 一致，无序号、两项服务费及备注列。
- [ ] 选某商户搜索，只显示该商户当前币种的代收统计。
- [ ] 对照蓝盛商户代收样本，成交金额、总单量、成功数和成交率一致。
- [ ] 列表钱包期初、期末为该商户代收钱包总额，与对应快照一致。

### 商户代付日终统计

- [ ] 进入本页，12 列及顺序与 PRD 4.4 一致，无序号、两项服务费及备注列。
- [ ] 选某商户搜索，只显示该商户当前币种的代付统计。
- [ ] 对照蓝盛商户代付样本，订单总金额、成交金额、未成交金额、总单量、成功数、未支付和成交率一致。
- [ ] “未支付”展示单量；列表钱包期初、期末为该商户代付钱包总额。

### 四页共用币种 Tab 与查询

- [ ] 给租户配置至少两个有效币种，四页各自显示对应 Tab；无授权币种不提供数据访问。
- [ ] 设置筛选并搜索后切币种，保留已应用条件、回第 1 页，计数及金额改为目标币种。
- [ ] 翻页后重置，商户／通道和日期清空、全部时间恢复、页码回 1，币种不变。
- [ ] 修改筛选但不搜索，再导出，文件仍使用此前已应用条件。
- [ ] 开始日期晚于结束日期时搜索，提示错误，原列表和合计不变。
- [ ] 在 UTC+8 日期边界测试今天／昨天／本周／本月，范围与自然日一致。
- [ ] 快速切币种并模拟响应乱序，最终列表、合计及导出属于选中的币种。
- [ ] 零记录时空态与零条一致、导出不可用；查询失败有重试提示，不能显示为零条成功结果。

### 四页共用分页与合计

- [ ] 用超过两页的数据测试 10／20／50 条、上一页、下一页及跳页，记录不重不漏。
- [ ] 输入 0、负数、非整数或超过总页数，提示错误且当前页不变。
- [ ] 翻页和变更每页条数，合计仍覆盖完整筛选；切商户／通道／日期／币种才随范围改变。
- [ ] 通道页、商户代收页及商户代付页分别核对所需金额和单量合计；成交率、钱包余额不累加。
- [ ] 用币种规定精度的边界金额核对列表和导出，汇总无截断或浮点误差。

### 通道备注编辑弹窗与保存

- [ ] 空备注点编辑，正确显示该行归属；输入多行并保存，行内回显与导出一致。
- [ ] 编辑原备注后取消、点关闭图标及按 Esc，原值分别保持不变，草稿不进入导出。
- [ ] 清空备注后保存，行内显示“—”，重新打开输入为空。
- [ ] 模拟保存失败，原值不变、弹窗及输入保留、无成功提示；重试成功后回显新值。
- [ ] 对同日同商户的不同通道、币种和方向分别保存，其他记录不串备注。
- [ ] 保存后搜索、翻页、切币种、刷新及重新进入，原记录仍读取已保存备注。
- [ ] 重新生成统计结果，交易指标按统计更新，人工备注仍保留。
- [ ] 备注包含引号、换行、网页片段或公式前缀，页面按文本展示，导出不执行文本内容。
- [ ] 无授权账号提交或篡改其他租户记录标识，保存被拒绝，原记录不变。

### 商户钱包明细弹窗

- [ ] 分别在商户代收、代付页点明细，弹窗类型、商户、日期和币种与该行一致。
- [ ] 对照同一快照核对四项金额，期末可用等于期末余额减冻结。
- [ ] 历史日读取历史日快照，修改当前余额后历史记录不被实时余额替代。
- [ ] 今日显示实际截至时间，金额对应其查询时点，不使用 Demo 固定时间。
- [ ] 关闭、关闭图标和 Esc 返回时，筛选、币种、页码和列表位置保持。
- [ ] 弹窗无流水、钱包、订单跳转与资金操作；打开／关闭不生成资金流水。
- [ ] 有效零余额显示为零；模拟快照读取失败时提示失败，不显示伪造零余额。

### 四页共用导出

- [ ] 在第 2 页导出，文件覆盖当前币种全部已应用筛选记录，数量等于总记录数。
- [ ] 分别导出四页，字段顺序与页面一致，不含序号、删除字段或钱包明细按钮。
- [ ] 核对文件金额与单量合计，结果与页面完整筛选合计一致，不混币。
- [ ] 保存备注后导出含保存值；仅编辑未保存或取消后的草稿不进入文件。
- [ ] 使用特殊字符备注导出，文字不损坏，换行／引号正确处理，公式前缀不被当成公式执行。
- [ ] 无导出权限或篡改租户／币种范围时导出被拒绝；导出失败无完成提示。

### 数据接入与交付核对

- [ ] 四页分别覆盖成功、未支付／未成交、零单量及蓝盛已定义的其他边界状态，对照计算一致。
- [ ] 当前租户页面、合计、钱包、备注及导出均无法访问其他租户数据。
- [ ] 查询及备注编辑前后，钱包余额、订单状态和资金流水无变化。
- [ ] 联调证据来自正式统计计算、钱包快照和持久化存储，不以 Demo 固定样例签收生产实现。
