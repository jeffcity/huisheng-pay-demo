## 需求背景与确认范围

租户端运营中心提供代付通道、代收通道、商户代收、商户代付四个独立日终统计页面。四页按币种 Tab 展示，不显示序号；两个通道页备注可编辑。商户页展示对应商户钱包期初、期末总额，冻结及可用在当前页只读明细查看。原经营报表与资金中心日终报表退出当前入口。

通道页不展示服务费、代理费、利润；商户页暂不展示商户服务费、通道服务费。成交率与未支付／未成交沿用蓝盛对应代码，开发逐页核对。报表不提供当日流水、订单或资金处理跳转。

## 演示与正式开发

需求文件为草稿。Demo 的四币种、固定日期、金额和钱包都是交互样例；备注为浏览器本地保存。正式数据、持久化、授权与蓝盛统计移植按开发清单接入，Demo 检查不代替生产验收。
