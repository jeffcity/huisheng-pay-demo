# 平台首页交易看板

用户确认“通道商的模板”指通道商统计模块，按每家已对接通道商跨租户汇总代收、代付数据。

## 展示范围

- 仅修改平台首页，保留 Tidewell 的冷灰底、白色卡片、深青色重点卡与紧凑表格。
- 今日按 UTC+8 计算，只展示 CNY；去掉首页旧首版提示、业务结构和租户排行。
- 顶部展示全平台合计、代收、代付，每项都有成交金额、订单数和成功率。
- 下方分别为通道商交易概览、租户交易概览。每个对象一行，代收、代付、合计三列分别显示金额、订单数及成功率。
- 当前为明确标注的模拟数据。已接入通道商来自通道商目录，租户来自平台租户目录；新建对象无交易时显示 0，成功率显示 —，不编造业务量。

## 统计口径

- 同一批今日创建的订单，统计截至刷新时间的状态；成交金额仅计其中成功订单的金额，不含退款、USDT 或费用。
- 订单数包含该范围内所有订单。成功率 = 成功订单数 / 已结束订单数；处理中、异常待处理不进分母。
- 通道商统计跨当前账号可见租户汇总。租户统计包含该租户所有已接入通道商；代收、代付、合计均可与顶部对账。
- 合计成功率按笔数加权，不平均租户、通道商或方向的百分比。
- 刷新三层数据使用一个截止快照；导出包含三层数据、两业务及合计，沿用页面范围、日期和截止时间。
- 没有全部租户权限的账号显示“授权范围合计”，先过滤授权租户再聚合通道商，不能泄露其他租户业务量。未知范围默认无数据。

## 开发任务与权限提示

- 后端提供平台、通道商、租户三层一致的今日 CNY 聚合数据，统一统计时间与笔数口径；通道商按稳定 ID 汇总，不按显示名关联。
- 前端接入真实聚合接口，保留零交易、无权限及无数据展示，窄屏采用四列紧凑表格。
- **必须维护菜单、页面和操作权限**：复用 `platform.dashboard.view` 查看/查询/刷新、`platform.dashboard.export` 导出；后端接口也必须校验权限及租户数据范围。
- 联调时核对现有角色是否已获得所需权限，不能只新增按钮而漏维护权限菜单；验证有权限可用、无权限拒绝、限定租户不越界与权限撤销后的导出拒绝。
- 不改动租户/商户页面、真实订单、钱包、系统费或结算方式。
