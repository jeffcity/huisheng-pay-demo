# 通道代收预付记录、通道代付预收记录

本次只做租户端，币种只保留人民币（CNY）。

**开发要做**

1. **在「运营中心 → 账户记录」下面新增两个页面。**
   - 通道代收预付记录：记录「代收通道管理」中，具体通道的「预付」变动。
   - 通道代付预收记录：记录「已授权通道商 → 代付」中，各通道商的「总预付」变动。

2. **对应的金额只要实际变化，就要留一条流水。**
   - 无论从哪个入口增加或减少，都要记下这次变化，并写清操作类型和备注。
   - 只改余额或剩余预付，没有改变上述字段时，不生成这两类记录。
   - 同一次变化只记一次，重复提交或重复处理不能多出流水。

3. **每条记录把对象和金额写清楚。**
   - 显示：序号、通道／通道商名称、编号、类型、币种、原金额、变动金额、变动后金额、变动时间、备注。
   - 原金额是变动前的值；变动金额说明这次增加或减少多少；变动后金额是操作完成后的实际值。
   - 例如：原金额100，减少10，变动后金额90。增加、减少要能区分。
   - 时间使用UTC+8，默认最新记录排在前面；类型不能显示「－」。

4. **展示和查询沿用商户预付记录页面。**
   - 支持按类型、变动时间范围、通道／通道商筛选，多个条件同时生效。
   - 支持搜索、重置、分页和导出；导出当前筛选结果的全部记录。
   - 保持紧凑表格，完整显示金额。用小问号说明金额来自哪个页面、哪个字段。

5. **权限一起维护。**
   - 补齐两个页面的菜单、查询、导出权限、后端校验和现有角色授权。
   - 只能查看当前租户有权访问的记录，不能查到或导出其他租户的数据。

**测试要验**

1. 增加、减少一笔代收通道「预付」，检查「通道代收预付记录」出现对应流水，名称和编号是这条通道。
2. 增加、减少一笔代付通道商「总预付」，检查「通道代付预收记录」出现对应流水，名称和编号是这家通道商。
3. 核对变动前、增减金额和变动后的值；没有其他变动时，最新流水的变动后金额应与来源页面对应字段一致。只改余额或剩余预付时，不应多出记录。
4. 检查重复处理不会重复记账，类型和时间筛选、重置、分页、导出可用；无权限账号及跨租户查询、导出会被拦截。
