# 租户端「系统费」开发任务清单

## 开发要做

1. **系统费入口与页面结构**
   - 在“租户端 → 资金中心 → 系统费”展示当前租户的CNY数据，按现有原型排列：钱包余额、统计月份、代收／代付系统费卡片、系统费日统计、钱包流水，并提供刷新。
   - 每个租户只有一个系统费钱包，代收、代付共用；余额展示当前剩余系统费，不随统计月份变化。租户端只读，不提供修改费率、调整余额或内部划转。

2. **与平台端收费设置联动**
   - 读取平台端“租户管理 → 系统费设置”的代收、代付配置，分别显示当前计费方式及费率：交易百分比显示“%”，按单笔显示“CNY／笔”；未设置与0费用分别展示。
   - 平台修改费率后，租户刷新可查看新配置；历史费用继续使用实际扣费时的费率快照。平台调整共用钱包余额后，租户刷新同步余额及人工调增／调减流水。

3. **按成功订单逐笔扣费**
   - 仅成功的CNY代收、代付订单计系统费，分别按成功订单金额乘费率，或按成功笔数乘单笔费用；两种方式不叠加，统一从共用钱包扣除。
   - 保留每笔费用的原精度，不逐笔四舍五入；同一租户同一订单只扣一次。费率未配置的在途成功订单保留为待计费，不能显示为免费。
   - 新单资格与平台配置一致：未允许负余额且余额不足时拒绝新单；允许负余额时按既有规则受理。在途订单继续处理并按成功结果计费；不绕过租户状态及业务费率校验。

4. **月度费用卡片与对账口径**
   - 按UTC+8订单成功月份查询，代收、代付分别展示已扣系统费、成功笔数、成功金额；费用按历史扣费记录汇总，待计费单独标记，人工调额不计入业务系统费。
   - 已生成月度对账单的月份沿用已保存的费用快照；未生成月份展示当前统计。月度对账只核对已扣费用，查询、生成、重复生成及导出均不再次扣款；月底按两业务分别汇总后到分，保留原精度供核对。

5. **系统费日统计及日期查询**
   - 按UTC+8成功日期倒序展示；代收、代付各列成功笔数、成功金额、已扣系统费，另列已扣系统费合计、待计费笔数，表尾显示当前查询范围合计。与月度卡片保持相同数据来源。
   - 提供开始日期、结束日期、查询和重置，支持单边日期及起止当天，仅查询所选月份内记录；无效日期、跨月份或开始晚于结束时提示，并保留上次有效结果。
   - 重置恢复整月；切月清空日统计日期，刷新保留有效条件。日统计查询不影响月度卡片或钱包流水条件，无记录显示空态。

6. **钱包流水与独立查询**
   - 统一展示代收系统费、代付系统费、人工调增、人工调减及待计费记录。字段包含流水单号、类型、原订单号与成功时间、原始订单金额、计费方式与费率快照、带正负方向的变动金额、扣费／调整时间、变动前后余额、操作人、原因及状态。
   - 提供订单号／流水号、流水类型、开始日期、结束日期、查询及重置；编号支持完整或部分匹配，回车可查询。日期按UTC+8扣费／调整日期筛选，待计费按成功日期，包含起止当天。
   - 流水查询独立于统计月份；切月不清空流水条件，刷新保留有效条件，重置恢复全部流水。人工调整无关联订单时显示“—”；待计费不展示虚构的扣款金额、时间或前后余额。
   - 原独立账户流水入口及关联编号跳转统一进入系统费页；紧凑列宽、完整金额，窄屏只在表格区域横向滚动，说明不堆成大段文字。

7. **权限菜单与跨端一致性**
   - 同步维护系统费页面、日统计查询、流水查询涉及的权限菜单、按钮权限、后端接口鉴权及现有角色授权；沿用既有流水授权，不因合并入口自动扩权，具体权限编码由开发核对。
   - 租户只能查询本租户数据，篡改租户编号或直接请求接口也不能越权；平台费率设置、允许负余额及余额调整仍由平台对应权限控制。
   - 平台租户列表的剩余系统费、租户详情余额、租户首页余额和本页余额读取同一钱包；平台昨日系统费按UTC+8实际扣费记录统计，与对应流水核对，不用当前费率回算历史。

## 测试要验

1. 平台分别设置两业务费率、按单笔、未设置及0费用后，租户页显示正确；平台调额后，两端余额、流水编号及前后余额一致，租户不能自行修改。
2. 成功、失败、取消、处理中、退款及待计费场景计费正确；重复回调和并发重试不重复扣费，修改当前费率不改变历史快照。两笔各0.005元费用合计0.01元，不能逐笔舍入成0.02元。
3. 两业务共用一笔余额；余额不足、允许负余额及租户停用等条件下，新单资格与平台规则一致，在途成功订单继续计费。
4. 跨日、跨月、订单成功与扣费不在同一天时，月度／日统计按成功日期归属，流水按实际扣费日期查询；已生成月账保持快照，所有查询与对账操作均不重复扣款。
5. 日统计日期查询、流水组合查询、回车、刷新、重置、切月和空态正确；两组筛选互不影响，人工调额不计入月度／日系统费。
6. 有权角色正常查询；无权限及跨租户请求被拦截。长编号、原精度金额及窄屏展示完整，菜单、按钮、接口与角色授权一致。
