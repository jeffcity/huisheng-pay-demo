# 产品决策记录

## 2026-11-02 代收订单三类时间

触发问题：用户在租户端“CNY代收订单”的提交／回调时间栏标注，要求增加支付时间，并上下排列且标明每个时间。

最终决定：同一栏按提交、支付、回调三行展示，每行带标签，未产生时间显示“—”。成功订单提供独立支付时间模拟值；提交和回调值保留原样。详情时间栏同步三类名称，现有只读查看与导出沿用原权限。代付页面不在本次范围。

决定原因：让用户区分订单提交、完成支付及回调的不同时间，不通过位置猜测含义。

影响文件：本地统一Demo/surfaces/tenant/public/legacy/sources/overview.html。

验证：构建及285项检查通过，完整冒烟通过。浏览器确认成功、待支付、处理中、失败及已过期订单的三行标签和缺省值，成功订单详情包含独立的提交、支付、回调时间。支付时间为Demo模拟数据，实际字段由后端订单事实提供。
