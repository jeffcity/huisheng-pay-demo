# 全局订单成功金额卡片开发任务清单

## 开发要做

1. **两端增加成功金额卡片**
   - 平台端“全局订单查询”、租户端“全局订单追踪”同步增加。
   - 展示成功代收金额、成功代付金额、成功金额合计，币种为CNY。

2. **明确统计口径**
   - 仅统计订单状态为“成功”的代收、代付订单金额，合计为两者相加。
   - 退款、失败、取消、处理中及异常待处理订单不计入，不以通知是否成功判断订单成功。
   - 金额精确相加，保留两位小数；没有符合条件的订单时显示CNY 0.00。

3. **跟随筛选条件汇总**
   - 汇总当前筛选条件下的全部结果，不只统计当前页；查询、重置及刷新后同步更新，翻页不改变合计。
   - 平台端按账号可查看的租户范围统计；租户端仅统计当前租户及账号获授权的商户范围。

4. **四张卡片同排展示**
   - 当前订单、当前异常、通知失败率、成功金额四张卡片排成一行。
   - 第四张卡片内，成功代收金额、成功代付金额及合计纵向排列，只显示字段和数值，不增加大标题或说明段落。
   - 小屏保持四卡同排，在统计区内横向滚动，避免撑宽整页。

5. **通过小问号查看说明**
   - 金额字段旁提供小问号，鼠标悬停或键盘聚焦时显示提示，离开后收起。
   - 提示使用自然语言说明“只算成功收款／支付的金额”“合计不含退款，翻页不会改变合计”，避免长篇说明常驻页面。

6. **权限菜单与接口校验**
   - 沿用两端页面查看权限；核对权限菜单、现有角色授权及统计接口鉴权，不因新增卡片扩大数据范围。
   - 统计结果必须与列表采用相同筛选和数据权限，后端校验租户及商户范围；无权限时不返回统计金额。
   - 本功能只读，不修改订单、余额或费用；CNY代收／代付业务订单页面保持原状。

## 测试要验

- 成功代收、成功代付分项与合计准确；退款及其他状态不计入，通知失败不影响已成功订单的金额统计。
- 查询、重置、刷新、分页及空结果展示正确，金额不重复、不丢失。
- 四卡同排、窄屏滚动及问号悬停／聚焦正常，字段和金额完整可读。
- 有权可查看，无权被拦截；平台租户范围、租户商户范围均不越权，统计与列表一致。
