# 租户端「代付通道商结算通知」

## 开发要做

1. **在通知中心增加消息类型。** 进入「通知中心 → 通知配置」，消息类型增加“代付通道商结算通知”。新增、修改和类型筛选都能使用；「发送的消息」也能按此类型查找。

2. **沿用现有方式配置机器人和群。** 选择该消息类型后，选择当前租户的通知机器人、填写TG群ID、编辑模板并保存。启用后接收结算通知，停用后不再接收。同一类型可配置多个接收群。自动结算开关的说明指向这里，通知按这里已启用的配置发送。

3. **手动、自动结算都发送结果。** 单家手动结算、一键结算和每天自动结算都发送。取消操作不发送。同一租户、同一批次的通道商合并通知，等本批次处理完成后发送；超时的明确写“超时，结果待确认”，不能写成成功。

4. **默认模板能一次展示多家通道商。** 展示租户名称与编号、手动／自动方式、执行时间（UTC+8）、批次号、通道商总数、成功／失败／待确认数量。下方逐家列出名称、编号和结果；成功的展示余额、剩余预付、总预付的结算前后数值，失败的展示原因。使用“通道商结算明细”变量自动带出本批次各家结果，不需要逐家配置模板。金额直接取实际结算记录，沿用现有结算规则。

5. **内容过长分条发送。** 每条保留同一个批次号，并标注“第1／3条”等序号。各家明细完整保留，金额和失败原因不能被截掉。单家结算也使用同一模板，数量显示1家。

6. **发送记录和重试能核对。** 在「发送的消息」中查看本批次实际发送的内容，保留发送当时的模板快照。通知失败只重试消息，不再执行一次结算；同一批次、同一接收配置的同一条消息不能重复发送。

7. **维护权限和租户范围。** 检查通知中心菜单、查询、新增、修改、启停、详情及导出的按钮权限、接口校验和现有角色授权。机器人、群、结算内容和发送记录均限定当前租户，不能把其他租户的数据发过去。

## 测试要验

1. **能配置、保存和查找。** 选择“代付通道商结算通知”，配置机器人和群后保存，切页回来仍能看到。类型筛选能找到，停用后不再发送；配置多个群时按各自启用状态接收。

2. **一条消息能看懂多家结果。** 同一批次有4家，2家成功、1家失败、1家超时待确认时，汇总数量正确，四家名称编号、金额或原因都能看到。只有1家时仍正常显示，0家失败不能显示成空值或模板变量。

3. **各种结算入口都能触发。** 分别执行单家手动、一键和自动结算，按对应批次生成通知。取消不发送，不同租户不合并；超时不能被写成成功。

4. **长内容和重试不漏、不重复。** 多家内容超过单条长度时，批次号相同、分条序号连续、明细齐全。发送失败后重试不会再调整金额，也不会把已发送成功的同一条重复发出。修改模板后，历史消息内容不变。

5. **权限与数据隔离有效。** 有权限账号能维护和查看，无权限账号不能操作；通过接口也不能选择其他租户的机器人、读取其结算内容或发送记录。
