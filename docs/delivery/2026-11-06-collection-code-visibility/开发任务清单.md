# 租户端「代收通道管理」子通道展示优化

## 开发要做

1. **每个通道默认只显示3条子通道**
   - 常用的排前面，其他按“今日成交”从高到低排；成交相同时保持原顺序。
   - 不足3条就全部显示。

2. **增加常用星标，每个通道最多3个**
   - 点空星设为常用，再点一次取消。
   - 已有3个时，再点第4个，提示“每个通道最多设置3个常用，请先取消一个”，不替换已有常用。
   - 不同租户、不同账号分别保存，刷新后保留。
   - 以前保存超过3个的，保留原默认列表中排在最前面的3个。

3. **增加“查看全部（N）／收起”**
   - 超过3条时显示入口，N是该通道的子通道总数。
   - 点击后在原表格里展开，只影响这一家通道；收起后恢复显示3条。

4. **支持名称、编码和批量搜索**
   - 通道、子通道都能按名称或编码查找。
   - 搜索框旁增加“批量搜索”，可以一次粘贴多项，用逗号、分号或换行分隔；匹配其中任意一项就显示。
   - 搜到的子通道直接显示出来，不用再点“查看全部”。重置后恢复默认列表。
   - 后续新增、需要批量搜索的页面，也提供批量输入入口和分隔提示。

5. **勾选范围要清楚**
   - “全选”只勾选当前显示的子通道，不选折叠隐藏的编码。
   - 收起后保留原有勾选，并提示隐藏数量，例如“已选5个编码，含隐藏2个”。
   - 批量删除确认框列出全部选中编码，包含隐藏的；取消删除不改变数据。

6. **保留原有操作，并同步权限**
   - 费率修改、启停、出码测试和产品绑定继续可用。
   - 修改费率时，勾选不能清掉输入；查询、展开、收起或标星前，提示先确定或取消费率修改。
   - 同步维护菜单、按钮权限及现有角色授权，后端检查权限和租户范围，避免运营看到入口却点不了，或查到其他租户数据。

## 测试要验

- 同一个通道能设满3个常用，第4个设不上；取消一个后能再设。不同通道分别计算3个上限，刷新后设置还在。
- 默认显示3条，展开能看全，收起恢复3条；常用优先，其余按今日成交排序。
- 用隐藏子通道的名称、编码都能搜到；一次粘贴多个关键词能查出对应结果，重置能恢复列表。
- 全选不选隐藏编码；已选编码收起后仍保留，数量提示和删除确认名单一致。
- 费率编辑不丢输入，原有操作正常；分别验证有权限、无权限以及不同租户的数据范围。
