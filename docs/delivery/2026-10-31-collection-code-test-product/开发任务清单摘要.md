# 出码测试选择产品｜开发任务清单

## 开发要做

1. 在租户端“代收通道管理 → 编码更多 → 出码测试”弹窗的通道方编码下方增加“选择产品”，显示产品名称及编码。候选仅包含当前租户已绑定当前编码的代收产品，不混入同一通道其他编码的产品。
2. 产品默认不选，选择后才能发起测试。关闭的产品标注“已关闭”且不可选；没有可用绑定产品时提示到“代收产品管理”绑定并开启产品，禁用“发起请求”。
3. 发起时重新校验产品存在、仍绑定当前编码且已开启，同时保留通道授权、通道及编码状态、支付金额和编码收款范围校验。将当前通道、编码、产品和金额一起用于本次测试；校验失败不生成支付地址。切换产品或修改金额清空旧地址，重新打开清空选择、金额和地址。
4. 同步维护出码测试入口与“发起请求”的菜单／按钮权限及后端接口鉴权，校验租户和产品绑定范围；核对目标及既有运营角色授权，不默认向全部角色开放。Demo只生成演示地址，正式测试请求沿用现有出码测试服务。

## 测试要验

1. 从不同通道及编码打开弹窗，名称与编码带入正确，候选仅为当前租户绑定当前编码的产品。其他租户、未绑定、已删除或仅绑定其他编码的产品不可选。
2. 未选择产品时提示选择；关闭产品不可选；无可用产品时显示绑定提示且不能发起请求。
3. 选中有效产品并填写合规金额后，按所选通道、编码及产品完成测试并展示返回地址。产品在弹窗打开后被删除、解绑或关闭，以及通道授权、状态或金额校验失败时，不返回新地址且不保留旧地址。
4. 切换产品、修改金额或重新打开弹窗时，旧地址正确清空；有权限的目标及既有运营角色可正常使用，无权限账号不可打开或发起请求，直接访问接口也不能绕过权限和租户范围校验。
