# 平台端「租户管理」优化开发任务清单

## 开发要做

1. **租户列表增加昨日跑量**
   - 按租户分别展示昨日代收跑量、昨日代付跑量，币种为CNY。
   - 昨日按UTC+8的前一自然日统计，页面明确显示统计日期；跑量只统计成功订单金额。

2. **租户列表展示系统费率**
   - 分别展示该租户当前的代收、代付系统费计费方式和费率。
   - 百分比显示“%”，按单笔显示“CNY／笔”；未配置显示“未设置”，配置为0时正常显示0。
   - 字段口径为平台向租户收取的系统费，与通道费用、商户服务费区分。

3. **租户列表展示昨日系统费与剩余余额**
   - 展示昨日代收已扣系统费、昨日代付已扣系统费及两者合计。
   - 按成功订单的实际计费快照汇总，不用当前费率重算历史；待计费订单单独标记，不能显示成免费。
   - 昨日经营统计读取实时记录，不因已生成月度账单而截断后续数据；月度对账沿用原规则，不重复扣费。
   - 每个租户只有一个系统费钱包，代收、代付共用；“剩余系统费”只展示一笔当前余额，并标注共用，不能拆成两个钱包或重复累计。

4. **提供系统费设置与余额调整入口**
   - 在租户列表操作列提供“系统费设置”，直接维护该租户代收、代付各自的计费方式与费率，保存后刷新列表。
   - 提供“调整余额”，对同一个系统费钱包执行调增或调减，展示调整前后余额，填写金额和原因，记录操作人、时间及审计。
   - 沿用现有金额校验、负余额限制与请求幂等规则；取消、校验失败或无权限时不变更余额。关闭租户只读。

5. **紧凑布局与导出同步**
   - 代收、代付数据在对应列上下排列；费用合计和共用余额清晰区分，金额完整展示。
   - 采用现有紧凑表格规范；窄屏仅表格区域横向滚动，筛选区和分页保持可操作。
   - 导出跟随当前筛选条件，包含统计日期、两业务跑量／费率／昨日费用、费用合计、待计费笔数及一笔当前共用余额，与列表一致。

6. **权限菜单与接口校验**
   - 同步维护页面查看、导出、系统费设置、余额调整涉及的权限菜单及按钮权限，并核对现有角色授权，避免页面可见但操作无权限。
   - 列表、导出及设置／调额接口均校验权限和租户数据范围；提交时再次校验，无权限或超范围时不返回数据、不修改配置或余额。
   - 复用现有权限体系，具体权限编码及角色授权由开发核对，不因增加入口默认扩大权限。

## 测试要验

- UTC+8跨日、跨月及无交易时，昨日日期与成功跑量正确；两业务数据及租户之间不混用。
- 百分比、按单笔、未配置、真实0费率和待计费场景显示正确；历史扣费不随当前费率变化，月账生成后新增成功仍进入昨日统计。
- 剩余系统费只有一笔共用余额；两业务扣费、余额调整及列表／详情／租户系统费页保持一致，重复提交不重复入账。
- 设置保存后列表刷新；关闭租户只读，取消、金额异常、余额限制、权限撤销或超范围操作均不改变原数据，并保留应有审计。
- 有权可查看及操作，无权被拦截；导出范围、字段、金额与当前筛选一致，窄屏、长金额和分页可正常使用。
