# 通道商管理开发任务清单摘要

## 开发要做

1. 列表增加“对接来源”“授权租户”两列，保持紧凑布局。
2. 对接来源选填，最多200字、支持换行；新增/编辑表单及列表双击均可维护，保存生效，取消保留原值，空值显示“—”。
3. 授权租户显示可见范围内人数，点击只读查看租户名称、编号、代收/代付授权和时间；按有效授权关系展示，无授权显示空态。
4. 修改来源写入操作审计，提交复验权限、范围和资料是否变化；重复保存不重复记录，不影响其他资料、授权和资金。
5. 必须维护权限菜单、按钮、接口和角色配置；编辑沿用通道商管理权限，名单沿用授权查看权限，名单、人数和导出按账号租户范围限制。

## 测试要验

- 验证新增、双击、保存、取消、清空、换行、长度、特殊字符及键盘操作；失败不写入。
- 验证人数与名单一致，业务方向正确；无权限及范围外访问拒绝，窄屏完整可查看。
