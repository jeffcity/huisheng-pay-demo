# 平台端与租户端本人修改密码｜开发任务清单摘要

## 开发要做

1. **账户菜单**：平台端和租户端公共页头右上角统一使用账户图标，点击展开“修改密码”“登出”；登出返回本端登录页。
2. **修改密码弹窗**：点击“修改密码”后显示只读当前登录账号；填写原密码、新密码、确认新密码、Google验证码，四项必填且有红星；提供取消、确定和关闭入口，密码默认隐藏。
3. **本人校验**：只修改当前登录账号的密码，不提供目标账号选择。验证原密码及本人Google验证码，新密码按本端既有密码规则校验，不能与原密码相同，两次新密码必须一致；Google验证码填写6位数字，有效性由后台验证。
4. **提交与失败**：提交期间禁止重复提交和编辑；任一校验不通过或提交失败，显示对应提示，密码保持原值，不跳转登录页。等待期间登录账号发生变化时拒绝本次修改。
5. **成功与重新登录**：修改成功提示“密码修改成功，请重新登录”，清空本次输入并返回本端登录页；当前账号使用新密码重新登录，原密码失效，继续沿用现有Google登录验证。
6. **取消与安全处理**：取消或关闭弹窗不保存，再次打开四项为空；密码及验证码不写入日志、地址栏或浏览器持久存储。平台、租户账号分别处理，修改本人密码不影响其他账号。Demo仅作为交互参考，正式原密码、密码更新和Google验证由后台完成。

## 测试要验

1. 平台端、租户端每个业务页面均可通过右上角账户图标展开两项菜单；选择登出进入正确端的登录页。
2. 修改弹窗显示实际当前账号且不可编辑，无其他账号选择；四项红星、密码隐藏与显示、取消和关闭正常，必填为空不能成功提交。
3. 分别验证原密码错误、新旧相同、两次新密码不一致、验证码不足6位、错误或过期验证码，均提示对应原因，原密码继续有效。
4. 连续点击确定不会重复修改；提交失败、修改期间切换账号均不误改原账号或其他账号，用户仍能重试。
5. 修改成功后返回本端登录页；原密码登录失败，新密码通过密码校验并继续Google登录验证，正确验证后进入本人授权页面。
6. 取消后密码不变，再次打开无上次输入；平台与租户及其他账号互不影响，日志、地址栏和浏览器持久存储中无密码或验证码。
