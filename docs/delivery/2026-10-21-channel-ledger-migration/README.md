# 蓝盛通道流水迁移至汇盛租户端

本项目统一覆盖“代收通道流水记录”“代付通道流水记录”两个页面，目标入口均为汇盛租户端运营中心。

- [汇盛统一 Demo](https://jeffcity.github.io/huisheng-pay-demo/)：租户端 → 运营中心 → 对应流水页面。
