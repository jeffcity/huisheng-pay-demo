# 蓝盛通道流水迁移至汇盛租户端｜开发任务清单摘要

## 开发要做

1. **统一迁移范围**：将蓝盛[代收通道流水记录](https://j3-web.newopsname.com/record/channel-pay-change)和[代付通道流水记录](https://j3-web.newopsname.com/record/channel-payout-change)作为同一个需求项目迁入汇盛。以蓝盛现有代码逻辑为准，沿用查询、重置、排序、分页、金额口径和导出处理。
2. **菜单与页面**：在汇盛租户端运营中心增加“代收通道流水记录”“代付通道流水记录”两个入口，接入统一菜单、标题、面包屑及样式，数据归属当前租户。
3. **代收流水**：保留平台订单号、商户订单号、类型、变更时间范围、通道筛选及搜索／重置／导出；迁移蓝盛原有11列和6种类型，具体顺序见PRD。
4. **代付流水**：保留同名筛选及操作；迁移蓝盛原有12列和5种类型。“商户订单号”用于筛选，“商户号”用于列表展示，分别沿用原字段含义。
5. **币种适配**：两个页面均只保留 CNY 页签，隐藏 USDT、TRX 等其他币种入口；列表及导出按 CNY 范围处理。
6. **展示与分页**：沿用蓝盛紧凑表格、金额精度及正负颜色、时间格式、长值查看、默认10条及10／20／50／100条分页。查询异常与边界沿用蓝盛既有处理，不增加行内资金操作。

## 测试要验

1. 从运营中心分别进入两页，菜单、标题、面包屑对应正确，其他运营中心页面正常使用。
2. 代收页的筛选、6种类型、11列表头及顺序正确；单项和组合查询、重置结果与蓝盛逻辑一致。
3. 代付页的筛选、5种类型、12列表头及顺序正确；用商户订单号查询返回对应记录，列表展示正确商户号。
4. 两页仅有 CNY，列表和导出均无其他币种；不混入其他租户或另一方向的流水。
5. 对照蓝盛验证金额、时间、排序、长值查看、分页条数及跳页；无结果、请求失败、日期异常和分页边界保持原处理方式。
6. 用正式接入数据回归导出范围、字段及格式，按蓝盛现有逻辑验收；查询与导出不改变资金数据，Demo 本地 CSV 不作为正式导出格式依据。
