# 全局订单查询优化 — 开发任务清单摘要

1. 列表时间栏展示创建、支付、回调三行，每行明确标签，统一 UTC+8；缺失值显示“—”，不得拿更新时间、状态变更或主动查单时间替代。
2. 订单详情与导出同步三类时间；详情继续保留更新时间，普通与退款订单均只显示明确存在的事实。
3. 压缩列宽、行距和内边距；长订单编号及结果摘要完整换行；小屏仅表格区域横向滚动。
4. 筛选区随宽度变为多列、两列或单列，查询、重置、分页及只读详情保持正常。
5. 必须同步核对权限菜单、页面/按钮权限、后端鉴权与现有角色授权：查看/查询/详情复用 platform.order.view，导出校验 platform.order.export。限定租户范围不得越界。
6. 验收成功、处理中、失败、退款与缺省时间；列表/详情/导出一致；窄屏可读；有权限可用、无权限拒绝。
