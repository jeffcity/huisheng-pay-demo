# 平台报表开发任务清单

## 开发要做

1. 平台端“报表模块”设置“日终”和“账户记录”两个可折叠菜单，迁移租户端当前六个日终与六个账户记录，原租户日终报表、通道日终报表、租户整体流水退出入口，首页卡片及旧内部下钻统一进入新报表。
2. 日终包含通道代收／代付、商户代收／代付、平台代收／代付；账户记录包含通道代收／代付流水、商户代收／代付流水、商户代收／代付预付记录。保留租户端现有CNY字段与业务口径，不提供代理日终、代理流水、USDT及代理费字段。
3. 每页增加租户筛选及租户栏位，显示租户名称与编号；平台查看有权访问的全部租户报表，可筛选单个租户。租户与通道、商户、订单号、类型、日期组合筛选，实体候选带租户信息，不将不同租户的同名实体混为一项。
4. 查询、重置、分页、空态、日期校验和导出沿用对应租户页行为。导出当前筛选的全部记录，包含租户信息；日终合计覆盖全部筛选记录，余额和预付快照不跨日期累加，成交率按成功数及总单量计算。
5. 平台端只查询、查看和导出；备注作为只读字段，不提供修改租户备注或资金操作。租户端页面、权限及数据范围保持原有规则。
6. 同步维护十二个菜单及查询／导出按钮权限、后端接口鉴权和角色授权。沿用已有角色的数据范围，全部租户权限可查所有租户，指定租户权限只查授权租户；不因迁移而扩大角色范围。查询和导出独立校验，目标及既有运营角色逐项核对；登录后的可达页面与权限事实同步新报表标识。

## 测试要验

1. 平台只展示十二个新报表入口，所属子菜单、选中状态及路径一致；每页字段与租户对应页一致并增加租户栏位。
2. 默认可见当前账号有权访问的全部租户；筛选单租户后，列表、合计、候选和导出不混入其他租户。同名或相同实体编号仍可按租户区分。
3. 验证组合筛选、时间边界、非法日期、分页及重置；导出包含全部已筛选记录，不能只导出当前页。快照字段不做跨日加总。
4. 查询和导出不改租户的订单、备注、钱包、余额或预付；租户端原有页面及单租户数据隔离不变。
5. 有权限、无查询权限、无导出权限及指定租户角色均按授权处理，直接访问接口不能绕过权限或租户范围。

- 日终：代收通道日终统计

- 日终：平台代付日终统计
- 账户记录：通道代收流水记录
- 账户记录：通道代付流水记录
- 账户记录：商户代收流水记录
- 账户记录：商户代付流水记录
- 账户记录：商户代付预付记录
- 账户记录：商户代收预付记录
