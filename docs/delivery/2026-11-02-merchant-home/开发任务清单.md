# 商户首页快速数据预览开发任务清单

## 开发要做

1. 商户首页按“代收数据”“代付数据”分组，仅展示 CNY。采用紧凑指标卡片，小屏自动换行。
2. 两组分别展示手续费、单费、当前余额、总订单金额、已收／已付金额、总订单数、已收／已付订单数、驳回订单数、驳回金额、冲正订单数、冲正金额。金额标明元，数量标明笔。单费指所选日期按笔收取的固定费用合计。
3. 顶部提供统计日期和查询按钮，按 UTC+8 自然日查询两组交易指标；当前代收余额、当前剩余预付标明当前值，不随所选日期变化。查询完成后两组日期与数据同步更新。
4. 所选日期无业务记录时，交易金额及订单数显示零并提示无记录。非法日期、查询失败或无权限时保留此前结果，不能以失败结果覆盖为零。Demo 提供三个日期模拟数据，实际接口按当前登录的租户与商户范围查询。
5. 首页移除 USDT 余额、USDT 账户、USDT 业务统计、自有地址收款卡片及相关快捷入口。首页快捷入口仅保留代收／代付订单、预付和日终。
6. 将“查询首页数据”按钮登记到权限菜单，权限标识为 merchant.dashboard.query；首页访问仍校验 merchant.dashboard.view。前端按钮与后端查询接口均需鉴权，并限制当前商户的数据范围。核对既有、目标运营角色授权，新增查询权限不自动扩大其他角色权限；超级管理员的全部按钮权限应包含此项。

## 测试要验

1. 首页存在两个业务分组，各十一项 CNY 指标，首屏没有 USDT 展示；窄屏数字和单位可读。
2. 查询不同日期，两组交易指标同时变化，当前余额保持当前口径；金额与数量的统计口径和对应业务查询一致。
3. 无记录日期展示零值；有记录日期恢复正常数据；空日期、无效日期、请求失败不覆盖原结果。
4. 有查询权限时可查询；无查询权限时按钮不可操作，直接请求同样被拒绝。切换账号或商户后不能保留前一账号的数据与查询状态。
5. 代收、代付、预付、日终、账号及通知等其他页面可继续进入，首页查询不改变订单、余额或资金记录。
