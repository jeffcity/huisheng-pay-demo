# 产品决策记录

## 2026-11-02 商户首页 CNY 快速预览

触发问题：用户指出首页 USDT 展示目前不适用，并提供按日期查询费用、余额、金额和订单数的参考截图。

考虑过程：截图主要体现代付，向用户确认是否同时展示代收。用户选择代收、代付分开各一组。首页按该范围调整，其他 USDT 业务页面与菜单不在本次修改范围。

最终决定：首页仅展示 CNY，代收和代付各十一项紧凑指标，共用统计日期查询。当前余额独立标明，不因统计日期变化；其余指标按日展示。提供三个日期样例及无记录日期的零值场景。移除首页 USDT 卡片、账户行、统计表与相关快捷入口。查询单独登记 merchant.dashboard.query 权限，已有超级管理员的全部按钮权限包含此项，其他角色不自动增加授权。只更新 Demo 展示，不接真实查询或改变资金。

决定原因：让商户快速看到两类业务的关键数据，同时区分当前余额和历史日统计。

影响文件：本地统一Demo/surfaces/merchant/demo.html；test/merchant-home-preview.test.mjs。

## 2026-11-02 商户端视觉统一

触发问题：用户要求商户端设计按已确认的 Tidewell 方向统一。

最终决定：保留首页两组共22项CNY指标及查询行为，将商户端白色侧栏、分组导航、顶栏、页签、按钮和首页卡片统一为冷灰蓝底、深青主色及单色线性图标。余额卡片使用深青底色突出，其他统计卡片为白底。菜单名称、权限、业务数据及操作流程保持现有口径。

决定原因：三端采用一致的视觉语言，便于运营在不同工作空间之间切换。

影响文件：本地统一Demo/surfaces/merchant/demo.html。
