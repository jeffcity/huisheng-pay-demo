# 订单时间与新增商户表单

本目录为本次GitHub交付只读快照。需求维护源位于同级需求文件夹，Demo只在本仓库维护；统一评审入口为根index.html。

- 平台端“全局订单查询”、租户端“全局订单追踪”：同栏纵向展示创建、支付、通道回调、通知商户四类时间，UTC+8。时间独立，缺失显示“—”，详情与导出一致。通道回调为收到通道通知；通知商户为最近一次发送，是否送达以通知结果为准。
- 租户端CNY代收与CNY代付业务订单保持本次调整前的展示和行为；四时间改动仅属于全局追踪。
- 租户端“商户管理 → 新增商户”：不提供商户类型与上级选择；使用原默认独立商户，不建立上级关系。既有商户类型、关系、编辑和筛选不变；白名单操作人MFA、限额、一次性密码与交付信息保留。
- [平台原文任务清单](../2026-11-02-platform-order-layout/开发任务清单摘要.md)保持原来的六节及子条目，只修改时间相关说明。

## 权限与验证

查看、详情及导出复用原权限，不新增操作权限；原接口鉴权、当前租户/授权商户范围及既有角色配置继续核对。有权限可用、无权限拒绝，不以字段展示扩大数据范围。

构建、304项检查、完整浏览器冒烟通过。实际浏览器验证两端全局页面四时间及详情/导出一致；CNY两业务页面恢复原展示；新增商户可创建，MFA错误不创建、正确后成功。全部数据为演示事实，未操作真实订单、通知服务或资金。

独立复核已确认六个共享订单的四时间在平台和租户全局页一致，并有跨端回归覆盖。
