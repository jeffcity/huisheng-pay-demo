# 新增商户

## 开发要做

1. 新增商户表单不显示“商户类型”和“上级主商户”，无需选择类型或上级即可创建，创建时不保存上级关系。
2. 表单最下方提供“操作验证”，验证码标注为“当前操作人 Google 2FA 验证码”。填写 API 请求 IP 白名单时校验，验证失败不创建商户。
3. 创建结果显示一次性密码，不显示有效期和域名机制说明；复制交付信息也不包含密码有效期。

## 测试要验

1. 新增商户不显示商户类型及上级选项，不受对应必填校验阻挡，创建成功后无上级关系。
2. 验证码位于初始限制之后，填写白名单且验证码错误时不创建，正确后可创建。
3. 创建结果及复制内容都有一次性密码，没有有效期和被移除的说明文案。
