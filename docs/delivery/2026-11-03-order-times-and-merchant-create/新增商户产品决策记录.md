# 产品决策记录

## 2026-10-16 新增商户表单与结果精简

- 触发问题：用户四条浏览器标注明确密码交付文案、上级条件与操作验证码位置。
- 考虑过程：上级字段已有 hidden 判断，但被 .field 的 display:grid 覆盖；验证码只需移动和明确当前操作人，保留填写白名单时原有校验，不能变成商户的2FA配置。
- 最终决定：增加上级隐藏字段的显式样式，类型切换同步隐藏、禁用与清空，并在保存时仅子商户读取上级关系；操作验证码独立放在表单底部；创建结果及复制信息不展示密码有效期，删除标注的说明段。
- 决定原因：按类型呈现必要字段，让验证行为和商户资料明确区分，精简结果页文案。
- 影响文件：租户 merchants.html、现有商户浏览器回归与统一构建入口。本次仅针对新增商户，不改其他管理员重置弹窗或商户端账号规则。


## 2026-11-03 新增商户取消类型选择

触发问题：用户在新增商户弹窗标注“商户类型取消”。

最终决定：仅新增弹窗移除商户类型及其子商户上级联动、必填校验；沿用原默认独立商户数据，不建立上级关系。其他资料、业务、限额、白名单与当前操作人MFA验证、成功信息保留。既有商户类型、关系、筛选和编辑不因本次字段取消而迁移。替代上一条新增表单按类型显示上级的规则。

决定原因：取消新增表单的类型选择，避免移除控件后创建依然依赖该控件。

影响文件：本地统一Demo/surfaces/tenant/public/legacy/sources/merchants.html、scripts/tenant-merchant-smoke.cjs、原开发任务清单第一条及对应验收第一条、Wiki新增商户概念。复用原新增权限，无新增权限点；本轮尚未推送，图谱待刷新。
