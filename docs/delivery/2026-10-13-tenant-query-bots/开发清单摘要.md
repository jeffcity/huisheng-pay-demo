# 租户端查单机器人配置：开发清单摘要

## 开发要做

1. 租户端「通知中心」新增「查单机器人配置」Tab，放代收、代付两块配置，各自保存；底部增加TG操作员。
2. 字段、开关和报警规则直接复用蓝盛现有实现。
3. TG操作员支持账号搜索、分页、新增、修改、启停和删除；维护TG用户名、系统管理员账号以及代收/代付业务和各自权限。
4. 迁移蓝盛完整机器人代码：在指定群收到已有指令后，查询并回复信息，指令和回复格式沿用蓝盛。
5. 配置、操作员、群绑定和查询数据按租户隔离，不能串用其他租户的数据。

## 测试要验

1. 两块配置能独立保存，再次进入正确回填；开关和报警行为与蓝盛一致。
2. 操作员新增、修改、回填及取消正常，两组业务权限独立，搜索、分页、启停和删除只影响目标记录。
3. 指定群发送有效指令，能收到正确回复；无权限的群或人员不能查询。
4. 不同租户的配置、操作员和回复互不影响，原通知功能正常。
